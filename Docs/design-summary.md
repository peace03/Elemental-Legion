# Elemental Legion 기획 요약

PC용 3D 탑다운 실시간 PvP 군단 전략 게임이다. 서버 한 곳에 최대 15명이 입퇴장하는 지속형 월드를 운영한다. 플레이어는 자연 원소로 시작해 군단을 움직이고, 적을 전향시키거나 핵을 모아 세력을 키우고 본진을 지킨다.

서버가 월드 상태와 모든 판정을 계산한다. 클라이언트는 명령만 전송하고 시야 안의 정보만 받는다. 비주얼은 Particle System, VFX Graph, Trail/Line Renderer, Shader Graph, 후처리 효과로 만든다.

- `shared/Runtime/`: 서버와 Unity가 함께 컴파일하는 C# 9 코드. UnityEngine을 참조하지 않는다.
- `shared/Data/gamedata.json`: 모든 게임 수치의 단일 원본. 기존 수치를 요청 없이 변경하지 않는다.
- `server/`: .NET 10 서버, 봇, xUnit 테스트 및 공유 코드 빌드 프로젝트.
- `client/`: Unity 6000.6.0f1 URP 프로젝트. `shared/`를 로컬 UPM 패키지로 참조한다.

M0 공유 코어에는 상성, 14종 효과와 6종 시너지, 이동·전향·핵·최소 양성·수비대 합류, 기하학적 시야와 내부 봇을 구현했다. 15명 × 50기 및 중립 238기의 분산·밀집 부하와 연속 진행을 콘솔에서 측정한다. 목표는 최대 부하 각각 p99 10ms 이하다. [검증 기록](Reports/2026-11-02-m0-validation.md)에 실제 결과와 한계를 남긴다.

UDP 접속·패킷, Unity 게임 화면, 탐색 기록, 건설·해금 진행, 중립 월드 생성·재생성, 유령·저장은 후속 단계다. M0의 양성소와 최대 부하 초기 상태는 사전 배치 시나리오이며 실제 시작·건설 경제를 대신하지 않는다.

세부 설계는 [원본 기획서](기획서/Elemental%20Legion%20게임%20기획서.md), 개발 제약과 단계별 완료 조건은 [AGENTS.md](../AGENTS.md)를 따른다. 원본 기획서와 데이터의 차이가 발견되면 임의로 수치를 맞추지 않고 확인한다.
