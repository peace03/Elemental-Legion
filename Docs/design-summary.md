# Elemental Legion 기획 요약

PC용 3D 탑다운 실시간 PvP 군단 전략 게임이다. 서버 한 곳에 최대 15명이 입퇴장하는 지속형 월드를 운영한다. 플레이어는 자연 원소로 시작해 군단을 움직이고, 적을 전향시키거나 핵을 모아 세력을 키우고 본진을 지킨다.

서버가 월드 상태와 모든 판정을 계산한다. 클라이언트는 명령만 전송하고 시야 안의 정보만 받는다. 원소는 Particle System, VFX Graph, Trail/Line Renderer, Shader Graph, 후처리 효과 중심으로 표현한다. 시설·거점 6종(원시핵, 포집기, 응집로, 점화로, 수호 위성, 자기권)은 3D 모델로 제작한다.

- `shared/Runtime/`: 서버와 Unity가 함께 컴파일하는 C# 9 코드. UnityEngine을 참조하지 않는다.
- `shared/Data/gamedata.json`: 모든 게임 수치의 단일 원본. 기존 수치를 요청 없이 변경하지 않는다.
- `server/`: .NET 10 서버, 봇, xUnit 테스트 및 공유 코드 빌드 프로젝트.
- `client/`: Unity 6000.6.0f1 URP 프로젝트. `shared/`를 로컬 UPM 패키지로 참조한다.

M0 공유 코어에는 상성, 14종 효과와 6종 시너지, 이동·전향·핵·최소 양성·수비대 합류, 기하학적 시야와 내부 봇을 구현했다. 15명 × 50기 및 중립 238기의 분산·밀집 부하와 연속 진행을 콘솔에서 측정한다. 목표는 최대 부하 각각 p99 10ms 이하다. [검증 기록](Reports/2026-11-02-m0-validation.md)에 실제 결과와 한계를 남긴다.

M1은 UDP 접속·군단 입력·예측·보간과 Unity 시작 화면을 구현했다. 사용자는 Unity 접속을 확인했으며 두 화면 이동·보간의 수동 확인은 보류다. M2에는 서버 시야/누적 탐색, v2 신뢰 변경분·표시 해제, 카메라별 URP RenderGraph 3D 연무와 대역폭 보고를 추가했다. [M2 검증 기록](Reports/2026-11-02-m2-validation.md)에서 자동 검사와 수동 보류를 구분한다.

M3는 전투 연출·양성·집결과 관측소 화면을 연결한다. M4 일반 서버는 중립·맵 핵, 자유 건설·업그레이드, 공성·패배, 유령 만료를 사용한다. M0 부하와 M3 데모는 별도의 사전 배치 시나리오다. 저장·계정 기반 복구는 M5 범위다.

현재 상시 월드는 야전 1~3번과 수비대 4번의 네 분대를 지휘한다. 신규 입장은 야전 8기·수비대 4기로 시작하며, 양성은 1~4기 단위로 목적 분대를 정한다. 양자 이동은 3초 시전과 성공 뒤 공유 60초 대기를 사용한다. PvP 전향은 후보를 분대가 확보하는 방식이고, 중립 전향은 즉시 적용한다. 현재 규칙과 시험 수치는 [메인 게임 개선안](기획서/2026-11-06-main-world-improvement.md) 및 [게임 규칙](Rules/gameplay.md)에 정리했다. 12기 시작, 본진 피해 상한 250HP/s, PvP 후보 20초 등은 시험값이며 사람 플레이 검증으로 정식 채택하지 않았다.

저장된 일반 월드는 스키마 3만 직접 복원한다. 지원하는 v1 JSON은 명시적 업그레이더 경로에서만 변환한다. 실제 운영 저장 일부의 데이터 해시 불일치가 확인되어 원본 보존 상태이며, 운영 변환·배포는 수행하지 않았다.

시간제 근원 쟁탈전은 별도 모드 후보로 보류한다.

세부 설계는 [원본 기획서](기획서/Elemental%20Legion%20게임%20기획서.md), 개발 제약과 단계별 완료 조건은 [AGENTS.md](../AGENTS.md)를 따른다. 원본 기획서와 데이터의 차이가 발견되면 임의로 수치를 맞추지 않고 확인한다.
