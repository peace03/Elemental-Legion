# 원소 14종의 본체·동작·전투 표현 개선

사용자가 원소 갤러리와 전투 시안처럼 실감 나고 역동적인 표현을 요청했고, 14종의 본체뿐 아니라 이동·공격·피격·전향·소멸까지 함께 개선하는 범위를 확인했다. 스타일 기준은 `Docs/Art/Concepts/2026-11-05-scenes/16-element-gallery.png` 및 전투 시안이다.

## 구현 방향

기존 `ElementalVisuals`의 인스턴스 렌더링과 제한된 Particle System 풀, `ElementArtProfile`, URP 셰이더를 확장한다. 원소마다 독립 GameObject·Update나 새 VFX 프레임워크를 만들지 않는다. 이는 750기와 중립 238기를 함께 표시하는 현재 구조에 맞춘 구현 선택이다.

- 자연: 물방울과 작은 위성 물방울, 위로 타오르는 불꽃, 나선형 회오리, 여러 덩이가 흐르는 연기, 얼음 파편, 공전하는 바위 조각, 갈라지는 번개.
- 에너지: 별빛 광륜, 중심 결정과 파편, 붕괴 핵과 입자, 검은 중심과 강착 고리, 중력 궤도, 청록·보라 자기장 고리, 잎과 생명 입자.
- 대기에는 개체별 위상이 다른 맥동·부유·회전, 이동에는 방향과 속도에 따른 자세·흔적, 공격에는 반동과 속성별 투사체/호, 피격에는 짧은 수축과 파편, 전향에는 응집과 확산, 소멸에는 속성에 맞는 흩어짐을 적용한다.
- 게임 수치·충돌 반경·서버 판정·시야 전송을 변경하지 않는다. 원소 몸체와 보조 입자는 기존 전장 표시 반경 안에 맞춘다. 시야에서 잊힌 대상의 상태와 효과를 정리하고, 중요한 전향·소멸 효과의 풀 예약을 유지한다.
- 크기·부유·회전·맥동·공격 반동 등 표현 설정은 기존 프로필에 인스펙터 항목으로 제공한다. UI와 시설 모델 제작은 이번 범위에 포함하지 않는다.

## 재사용

설치된 Unity Technologies Particle Pack의 불꽃·연기 플립북과 물방울·물 노멀, CC0 Kenney Particle Pack을 그대로 사용한다. 경로와 라이선스는 `Docs/third-party.md`의 기존 M3 기록을 재사용한다. 공식 VFX Graph 샘플은 기존 조사에서 HDRP 의존성이 확인돼 이번에도 통째로 도입하지 않는다. 새 외부 패키지·유료 에셋은 추가하지 않는다. 몸체 메시와 셰이더는 현재 프로젝트 코드에 맞춰 제작한다.

## 작업과 검증

- [x] 기존 988기 렌더링 기준 표본과 14종 갤러리 화면을 확보한다.
- [x] 프로필·고유 메시·동작·이벤트 수명과 정리의 회귀 테스트에서 현재 부족한 표현을 확인한다.
- [x] 14종의 고유 메시와 재질을 구성하고 프로필 참조를 갱신한다. 기존 자산 GUID와 사용자 씬을 보존한다.
- [x] 본체 동작과 이동 흔적, 서버 확정 사건의 전투 효과를 기존 렌더러와 풀에 연결한다.
- [x] Unity 컴파일·EditMode와 .NET 빌드·테스트를 통과시킨다. 갤러리·전투의 서로 다른 시점과 988기 렌더링 표본을 비교한다.
- [x] 독립 리뷰 후 결과와 미검증 항목을 보고한다. Play 및 Windows Player 전체 프레임 결과와 Editor 오프스크린 측정을 구분한다.

원본 씬을 열어 저장하거나 Play에 진입하지 않는다. `M3SceneSetup.Configure`의 전체 프리팹 재구성은 실행하지 않는다. 리뷰에서 자기권이 물 원소 메시를 공유하는 결합을 확인해, LegionClient 프리팹과 ElementGallery 씬에 기존 구형 메시 참조 한 항목만 추가하고 원소와 분리한다.

## 결과

14종 고유 메시와 재질, 본체·전투 동작, HDR 발광을 연결했다. 리뷰에서 찾은 자기권 메시 공유와 추가 카메라 컴포넌트 정리 문제를 수정했다. 회귀 테스트는 40/40, .NET 테스트는 322/322가 통과했다. 원소 아트 설정을 반복 실행해 프로필 ID·입자 참조·메시 GUID 보존을 확인했다.

오프스크린 검증은 Volume을 갱신하는 StandardRequest, HDR 텍스처, GPU 완료 1픽셀 읽기 및 화면 색 공간 변환을 사용하도록 보완했다. 최종 988기 표본의 동기화 포함 처리 p95는 14.26ms, GPU 표본 p95는 7.80ms였다. Player의 전체 프레임·네트워크 실전·사람의 Play 확인과 구분한다. [검증 보고](../Reports/2026-11-05-element-visuals.md).
