# 시설 5종 연출 적용 계획

[승인한 전장 시안](../Art/Concepts/2026-11-11-facility-vfx/facilities-ingame.png)의 다섯 효과를 제공 모델에 연결한다. 실전 카메라에서 원시핵의 결정 구체, 포집기의 금빛 흡입, 응집로의 푸른 유동선, 점화로의 보라 수정과 링 세 개, 수호 위성의 배치 원소가 각각 구분돼야 한다.

- 원시핵의 면각구와 응집로의 유동선을 별도 메시와 HDR 재질로 만든다. 기존 URP 카메라의 Bloom을 사용한다.
- 점화로는 실제 모델 부품을 가져올 때 수정과 링 세 개를 구분한다. 완공 상태에서만 수정이 발광하고 금속 링을 높이 방향으로 움직인다. 수호 위성은 지정한 원소의 본체 메시와 입자를 중앙에 띄운다.
- 포집의 기존 서버 판정에서 실제로 승리한 포집기의 ID를 사건에 넣는다. 클라이언트는 현재 관측된 완공 포집기로만 파티클을 모으고, 흡입 끝에 중심 재질을 밝힌다. 시야 해제와 세션 초기화 때 연출을 정리한다.
- 서버 회귀 검사로 승자와 시야를, Unity 검사로 자산 연결과 표시 수명을 확인한다. 실전 프리팹을 사용한 Editor 렌더에서 정상 배율과 확대, 흡입 중간과 완료, 점화로의 두 시점을 비교한다.

Unity 공식 [VFX Graph 샘플](https://github.com/Unity-Technologies/VisualEffectGraph-Samples)의 스트립과 입자 흐름을 참고했다. 기존 Particle System과 배치 렌더에 필요한 흐름을 직접 구현하므로 샘플이나 추가 패키지를 가져오지 않는다. 발광은 현재 카메라 [URP Bloom](https://docs.unity3d.com/6000.0/Documentation/Manual/urp/post-processing-bloom.html)의 HDR 입력을 사용한다.
