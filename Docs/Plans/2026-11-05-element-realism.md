# 원소 사실주의 표현

사용자는 사실감에 동의하고, 이동 상태는 `natural-mobile-v2.png`·`energy-mobile-v2.png`, 대기 상태는 `natural-idle-v3.png`·`energy-idle-v3.png` 방향으로 확정했다. 14종 본체와 대기·이동·공격·피격·전향·소멸이 범위다. 이미지는 목표 시안이며 실제 Unity 결과와 동일하다고 간주하지 않는다.

## 구현 범위

- 원소는 바닥 위에 응집한 비인간형 개체다. 눈·팔다리를 추가하지 않는다. 이동 때 흐름·잔상이 늘고, 멈추면 중심부가 응집한다. 얼음·흙·결정은 부유 파편, 생명은 뿌리·이끼·잎의 군집이다.
- 물은 굴절·반사·세부 노멀, 불·연기는 설치된 실제 플립북과 투명 입자, 얼음·암석은 표면 질감과 파편 메시를 사용한다. 추상 에너지는 얇은 필라멘트·빛 왜곡·실제 물질의 반응으로 표현한다. 불투명한 기하학 링으로 원소를 대신하지 않는다.
- 실제 Unity 비교에서 단순 3D 메시만으로 승인 시안의 질감을 재현하기 어려워, 최종 유닛 본체는 승인 시안을 바탕으로 만든 투명 대기·이동 이미지와 실시간 입자·3D 파편을 결합한다. 자연·에너지별 4×2 시트 총 네 장, 상태별 14칸을 사용한다. 카메라 정면을 향하는 면에 표시하므로 유체의 실시간 체적 시뮬레이션이나 모든 각도의 3D 재질과 동일하지 않다.
- 14종마다 인스턴스 배치 한 개와 재사용 입자층을 유지한다. 기존 3D 메시·재질은 타워 장식·발사체·파편·빙결·방벽에 보존한다. 외형은 클라이언트 표현이며 서버 판정·시야·밸런스는 바꾸지 않는다. 소유 색상 링·건물과 원소 고유 재질을 분리한다.
- 기존 원소 셰이더·ArtProfile·모션·VFX 풀을 확장한다. 표면 세부 재질의 수치는 머티리얼 인스펙터, 동작은 프로필에 노출한다. 새 패키지보다 설치된 리소스를 우선한다.

## 제작과 검토

- 그래픽 담당은 확정 시안의 실루엣·재질·입자 연출 및 재사용할 표면 자료를 준비한다. 구현 담당은 유지보수할 메시 생성 도구·셰이더·대기/이동 연결 코드를 맡는다. 같은 Editor는 한 명씩 사용한다.
- 원본 자산의 GUID를 보존하고 수정 전에 복구본을 `.artifacts/element-realism/before/`에 보관한다. 기존 씬·프리팹 연결과 소유 색상·호스트 승계 변경을 보존한다.
- 제작자와 별도의 시각 검토자가 실제 카메라에서 대기·이동·전투 장면을 확인한다. .NET/Unity 컴파일·EditMode를 확인하고, 기존 M3 probe의 같은 조건으로 988개체 밀집 및 전투를 측정한다. Windows Player·사람의 Play 검증은 별도로 남긴다.
