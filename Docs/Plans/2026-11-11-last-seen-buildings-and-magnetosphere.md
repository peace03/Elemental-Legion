# 적 시설의 마지막 관측과 자기권 시안 계획

2026-11-11 작성. 정찰로 확인한 적 시설을 시야가 닫힌 뒤에도 전장과 미니맵에서 찾을 수 있게 한다. 자기권은 실제 플레이 카메라에서 본진을 감싸는 자기장으로 읽히도록 이미지 시안을 먼저 만든다.

## 1. 정찰한 적 시설을 다시 볼 때까지 표시

### 플레이 중 보이는 상태

| 상황 | 표시 |
| --- | --- |
| 지형만 탐색함 | 탐색 지형을 표시한다. 시설은 실제로 관측한 때부터 표시한다. |
| 적 시설을 현재 관측함 | 현재 외형과 상태를 표시한다. 관측할 때마다 시설의 위치, 종류, 소유 색, 건설·완공 상태 등 화면에 필요한 값을 기록한다. |
| 시야에서 벗어남 | 전장에는 낮은 채도의 외형을, 미니맵에는 테두리 표식을 남긴다. 카드를 열면 ‘마지막 관측’으로 표기한다. 관측 당시 공사 중이었다면 그 모습에서 멈추며, 체력을 표시하는 경우에도 관측값으로 표기한다. |
| 시설 위치를 다시 확인함 | 시설이 있으면 현재 모습으로 바꾼다. 서버가 그 자리를 확인했고 기존 시설이 없으면 기억 표식을 지운다. 같은 자리에 새 시설이 보이면 새 시설을 표시한다. |

첫 구현은 전장과 미니맵에 같은 관측 기록을 쓰고, 관측 기록은 접속 중인 월드에서 유지한다. 새 접속이나 월드 전환, 호스트 승계로 관측 기준을 다시 받을 때는 기록을 초기화한다.

### 구현 순서

1. **서버에서 빈 자리 확인을 전달한다.** 현재 `Forget`은 관측 목록에서 빠진 ID를 전송한다. `VisionGrid`의 한 칸은 시야와 일부만 겹쳐도 밝아진다. 따라서 칸 표시만 보고 시설이 없다고 판단하면 경계에서 오삭제가 생긴다. `FogReplicationState`에 수신자별로 이미 전송한 건물 ID와 당시 좌표를 상한이 있는 버퍼로 보관한다. `WorldView.CanSeePoint`로 그 좌표를 다시 확인할 수 있고 현재 관측 목록에 그 ID가 없을 때만, 기존 신뢰 전송 경로에 빈 자리 확인을 추가한다. 오래된 확인은 틱과 시야 revision을 대조해 처리한다. 전송 형식을 바꾸는 경우 프로토콜 버전과 [프로토콜 문서](../protocol.md)를 갱신한다. [시야 그리드](../../shared/Runtime/Sim/VisionGrid.cs) · [시야 전송](../../shared/Runtime/Net/FogReplicationState.cs)
2. **클라이언트에서 당시 모습을 복사해 보관한다.** `ClientBootstrap`에서 현재 관측을 처리할 때, 시야 기준이 맞는 `GameplayFrame.Buildings`의 적 시설만 ID별 값으로 복사한다. 서버의 빈 자리 확인을 받으면 해당 기록을 삭제한다. 기록 상한에 도달하면 양쪽이 같은 기준으로 오래된 항목부터 정리한다. 전장 외형과 미니맵 표식은 이 기록을 함께 사용한다. 과거 시설은 표시용 데이터로 유지하고, 이동 예측·건설 검사·공격 대상은 현재 관측 경로를 사용한다. 과거 자기권은 외형만 남기며 보호막의 흐름이나 피격 반응은 현재 관측에서만 재생한다. [전장 연결](../../client/Assets/_Project/Scripts/Runtime/Bootstrap/ClientBootstrap.cs) · [미니맵](../../client/Assets/_Project/Scripts/Runtime/UI/ObservatoryMap.cs)
3. **경계와 시야 유출을 검증한다.** 두 플레이어로 발견 → 이탈 → 안개 속 파괴·완공·재건 → 재정찰을 재현한다. 안개 속 사건 동안 표식과 받은 데이터가 같고, 재정찰할 때만 갱신되는지 비교한다. 시설 위치가 여전히 안개에 있는 시야 경계, 지연 패킷, 중복 표시, 연결 초기화를 함께 테스트한다. 건물 기억 표식은 기존 배치와 미니맵 좌·우클릭을 방해하지 않도록 확인한다.

## 2. 자기권 이미지 시안과 Unity 적용

현재 완공된 자기권은 본진 중심에서 구형 메시를 그린다. 시안은 **얇고 투명한 경계면을 따라 자기력선이 휘어 감기는 모습**으로 잡는다. 자기력선은 본진 위와 바닥 쪽에서 모이고, 보호 영역의 바깥쪽에서는 크게 휜다. 경계는 옆에서 보이는 가장자리와 공격이 닿는 부분에서 선명하게 읽히고, 중앙의 원시핵과 원소는 안쪽에서도 보인다. 실제 자기권의 압축된 앞면과 길게 휘는 자기력선을 형태 참고로 삼는다. [현재 자기권 렌더링](../../client/Assets/_Project/Scripts/Runtime/Legion/ElementalVisuals.cs#L390) · [NASA 자기권 도해](https://science.nasa.gov/blogs/the-sun-spot/2023/09/26/earths-magnetosphere-and-plasmasheet/)

1. **시안 한 장을 먼저 제작한다.** 실제 전장 캡처를 참조해 동일한 카메라와 원시핵 크기로 두 장면을 나란히 만든다. 왼쪽은 완공 후 평상시의 얇은 경계와 느린 흐름, 오른쪽은 피격 지점 주위에서만 밝아지고 휘어지는 막이다. 어두운 지면에서 경계가 읽히는지, 원시핵·유닛·체력 표시가 보이는지 확인한다. [전장 참조 캡처](../../.artifacts/ui-controls/previews/Hud-1920x1080-100.png)
2. **확정한 외형을 기존 Unity 표현에 연결한다.** 자기권에 쓰는 구형 메시와 소유 색을 바탕으로 전용 URP 재질을 시험한다. 외곽 밝기, 자기력선의 밀도, 흐름 속도, 피격 반응의 강도와 지속 시간을 Inspector에서 조절한다. 배치 미리보기와 건설 중에는 자리와 상태가 읽히는 정도로 표시하고, 보호막의 흐름은 서버가 완공을 확정한 뒤 시작한다. 피격 반응은 서버가 공개한 사건의 위치와 방향을 사용한다. 기존 서버의 설치 위치·비용·건설 시간·흡수 판정에 맞춰 표현한다. [게임 규칙](../Rules/gameplay.md)
3. **같은 전장 카메라에서 적용 전후를 확인한다.** 미설치, 건설 중, 가동, 피격, 파괴, 안개 속 마지막 관측을 캡처한다. 720p와 1080p에서 원시핵과 병력이 가려지는지, 여러 기지의 투명 막이 겹쳐도 상태를 읽을 수 있는지 확인한다. 동일 조건에서 투명 효과의 드로 콜과 GPU 프레임 시간을 비교한다.

평상시와 피격 시를 같은 구도로 비교하는 1774 × 887 시안을 제작했다. [비교 이미지](../Art/Concepts/2026-11-11-magnetosphere/magnetosphere-comparison-v1.png) · [생성 프롬프트](../Art/Concepts/2026-11-11-magnetosphere/prompt.md)

## 완료 기준

시안에서 평상시와 피격 상태의 경계가 읽히면 Unity 적용으로 넘어간다. 적 시설 기록은 두 클라이언트의 시야 경계와 재정찰을 확인한 뒤 완료로 판단한다. 저장소 검증 기준에 따라 서버·공유 코드의 .NET 빌드와 테스트, Unity Editor 컴파일과 EditMode 검사, 실제 화면과 Play 결과를 기록한다. [작업별 검증 기준](../Rules/workflow.md#작업별-검증)

## 구현 및 검증 기록

- 서버는 이미 해당 수신자에게 보낸 적 시설만 연결당 1,024개까지 기억한다. 이전 시설의 좌표가 정확한 시야에 다시 들어왔을 때 빈자리를 확인한다. 상한을 넘으면 시야 밖 기록을 오래된 순으로 정리한다. 전장과 미니맵은 같은 관측값을 쓰며, 고정 카드에는 ‘마지막 관측’과 관측 당시 체력·건설 상태를 표시한다. 서버와 클라이언트는 프로토콜 v24를 사용한다. [시야 패킷](../protocol.md#시야와-종류별-표시-해제)
- .NET 솔루션 빌드와 전체 테스트 839개를 통과했다. 두 수신자의 관측 범위를 따로 검증했고, 안개 속 완공·파괴·재건, 동일 격자 안에서의 재진입, 부분 패킷, 손상된 제거 목록을 재현했다. 첫 실행은 이전 버전 23을 기대하는 테스트 세 건이 실패했고, v24로 갱신해 전체를 다시 실행했다. [빌드 로그](../../.artifacts/last-seen-buildings/dotnet-build-after-protocol-fix.log) · [테스트 결과](../../.artifacts/last-seen-buildings/last-seen-buildings-rerun.trx)
- Unity 6000.6.0f1 Editor 컴파일과 EditMode 테스트 212개를 통과했다. 시야 패킷이 앞서 도착해도 고정한 마지막 관측 카드가 유지되는지 확인했다. 2인 시뮬레이션의 시야·시설 패킷을 실제 프리팹에 전달해 1280 × 720에서 전장 외형, 미니맵 표식, 카드가 함께 전환되는 것을 확인했다. 첫 캡처에서 카드 설명과 체력이 겹쳐 카드가 활성화된 후 텍스트 높이를 계산하도록 고쳤다. 어두운 지면에서 건설 중 외형이 읽히도록 관측 표시의 밀도와 건설 중 밀도 중 작은 값을 적용했다. [EditMode 결과](../../.artifacts/last-seen-buildings/editmode.json) · [관측 중](../../.artifacts/last-seen-buildings/01-visible.png) · [시야 밖에서 파괴된 뒤](../../.artifacts/last-seen-buildings/02-remembered.png) · [빈자리 재확인](../../.artifacts/last-seen-buildings/03-cleared.png)
- 실제 2인 Unity Play와 Player 빌드, 장기전 최대 관측 수의 성능 측정은 남아 있다. 자기권은 이미지 시안까지 제작했다.
