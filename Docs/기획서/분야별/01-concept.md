# 콘셉트와 게임 비전

[분야별 기획서](README.md)

## 개편안

**근원 쟁탈전**에서 별의 씨앗은 즉시 움직일 수 있는 원소 32기를 이끈다. 가까운 핵을 모아 첫 증원을 보내고, 사냥·견제·수비 중 어디에 분대를 보낼지 고른다. 중앙 관문이 열리면 전력 격차를 공간 판단으로 뒤집을 기회가 생긴다. 첫 본진 습격에 대응하고 한 번 복구할 수 있어, 원정을 나갈 때도 돌아올 방법이 있다. [전체 흐름](02-game-design.md) · [승패](05-modes.md)

짧은 보상은 핵 습득과 실제로 도착하는 증원이다. 중간 목표는 원소를 섞고 분대를 나눠 길목을 잡는 것이며, 한 판의 결말은 관문을 지키거나 빼앗는 일로 드러난다. 결과 화면에서 같은 방의 다음 판으로 이어진다. 이 흐름은 .io 사례를 바탕으로 세운 가설이며 첫 보상 시간과 재경기 선택을 사람 플레이에서 확인한다. [.io 사례](14-io-references.md) · [플레이테스트](12-playtest.md)

## 기존 콘셉트

플레이어는 별의 씨앗이 되어 자연 원소 3기로 시작한다. 하나의 군단을 직접 움직여 교전할 상대를 고르고, 쓰러뜨린 원소를 아군으로 전향시키거나 원소 핵을 모아 새 병력을 양성한다. 본진을 비우고 어디까지 나갈지 결정하는 동안 다른 씨앗도 세력을 키운다.

| 항목 | 현재 기획 |
| --- | --- |
| 장르와 플랫폼 | PC용 3D 탑다운 실시간 PvP. 거점 약탈과 군단 직접 조작을 결합한다. |
| 플레이어 역할 | 원소를 중력으로 끌어모아 더 큰 행성이 되려는 별의 씨앗 |
| 플레이 공간 | 입퇴장이 가능한 지속형 월드가 원형이다. 현재 LAN·인터넷 방과 방에 추가할 수 있는 AI도 제공한다. 정원은 사람과 AI를 합쳐 최대 15명이다. |
| 핵심 행동 | 탐색해 상대와 자원을 찾고, 상성과 군단 구성을 보고 교전 여부를 고른다. 전향·양성으로 늘린 원소를 이끌며 본진에 투자한다. |
| 성장의 차이 | 교전에서 얻는 원소는 그 속성을 유지한다. 출발 원소 하나에서 혼합 군단으로 성장하고 시너지 조합을 만들 수 있다. |
| 프로토타입 목표 | 멀티플레이에서 군단 이동, 성장, 공성, 본진 방어와 재시작까지 경험할 수 있게 한다. |

## 플레이에서 확인할 긴장

원본은 교전에서 전향으로 얻는 아군이 양성보다 많아지도록 설계했다. 교전은 성장의 기회이면서 본진을 비우는 선택이다. 이 선택이 성립하려면 이동 중 원소 조합의 장점이 읽히고, 습격을 받은 플레이어에게 상황을 파악하고 반응할 시간이 있어야 한다. [원본 기획의 핵심 루프](../Elemental%20Legion%20게임%20기획서.md#핵심-루프와-건설)

본진을 지키는 선택의 폭, 한 번에 지휘할 원소 수와 배치 단위, 열세를 되돌릴 여지, 성장 보상과 재도전의 체감은 현행과 개편안을 같은 조건에서 비교한다. [플레이테스트 항목](12-playtest.md#플레이-피드백을-확인할-시나리오)
