# 콘텐츠 기획

[분야별 기획서](README.md)

군단은 자연 원소로 출발해 전향과 양성으로 14종 원소를 조합한다. 원소가 거치는 전투 효과와 시너지, 본진 주변에서 쓰는 시설을 아래에 정리한다. 콘텐츠 구성은 현행 14종 원소, 6개 시너지, 6개 시설을 유지한다. 신규 경기 규칙과 목표물은 [시스템 기획](03-systems.md#개편안-시험값)을 참고한다. [수치 원본](../../../shared/Data/gamedata.json) · [게임 규칙](../../Rules/gameplay.md)

## 원소 분류 및 전투 역할

| 그룹 | 원소 | 전장 역할과 현재 고유 효과 |
| --- | --- | --- |
| 자연 | 흙 `earth` | 근접. 현재 전용 효과 데이터가 없다. |
| 자연 | 얼음 `ice` | 근접. 공격을 맞힌 적의 공격 속도를 낮춘다. |
| 자연 | 불 `fire` | 근접. 화상을 부여해 시간에 걸쳐 피해를 준다. |
| 자연 | 연기 `smoke` | 중거리. 주변 적의 공격 사거리를 낮추는 오라를 만든다. |
| 자연 | 물 `water` | 원거리. 적에게 젖음 상태를 부여해 연계 효과의 조건이 된다. |
| 자연 | 바람 `wind` | 원거리. 높은 공격 속도로 연타한다. 독립 상태 효과는 없다. |
| 자연 | 번개 `lightning` | 원거리. 맞은 뒤 인접한 적 하나에게 공격 일부를 연쇄한다. |
| 에너지 | 암흑 물질 `dark_matter` | 근접. 준 피해 일부를 회복한다. |
| 에너지 | 자기장 `magnetism` | 근접. 주기적으로 주변 아군에 피해를 흡수하는 방벽을 준다. |
| 에너지 | 결정 `crystal` | 중거리. 주변 아군의 공격 속도를 높이는 오라를 만든다. |
| 에너지 | 중력 `gravity` | 중거리. 공격에 범위 피해가 따른다. |
| 에너지 | 빛 `light` | 원거리. 공격이 정렬된 여러 대상까지 관통한다. |
| 에너지 | 붕괴 `decay` | 원거리. 방사성 지속 피해를 준다. |
| 에너지 | 생명 `life` | 원거리. 플레이어 소속일 때 가까운 부상 아군을 회복한다. |

자연 원소만 시작 원소로 고를 수 있다. 자연·에너지 구분, 역할, 기본 공격 수치와 효과의 세부 값은 [`gamedata.json`의 `elements`](../../../shared/Data/gamedata.json)에 둔다. 원소별 우주 해석과 캐릭터 성격은 [원본 세계관 및 원소 캐릭터 설정](../Elemental%20Legion%20게임%20기획서.md#원소-캐릭터)에 있다.

## 속성 상성

각 그룹은 일곱 원소가 한 바퀴 도는 상성 고리다. 고리에서 다음 세 원소는 이기고, 앞의 세 원소에는 불리하다.

- 자연 고리. 물 → 불 → 바람 → 연기 → 얼음 → 흙 → 번개 → 물.
- 에너지 고리. 빛 → 결정 → 붕괴 → 암흑 물질 → 중력 → 자기장 → 생명 → 빛.

상성 배율과 에너지 원소별 자연 카운터의 배율은 `gamedata.json`의 `rings`, `crossCounters`, `matchups`를 따른다. 확정되지 않은 밸런스 조정치와 데이터 값은 [수치 밸런스](./09-balance.md)에 한 번만 적는다.

## 시너지 반응

시너지는 두 원소가 같은 플레이어의 전투 군단에 있을 때 조합으로 활성화된다. 실제 발동에는 첫 효과가 만든 상태와 두 번째 효과의 공격 조건이 함께 필요하다. 수비대의 효과는 적용되지만 수비대만으로 군단 시너지의 원인을 만들지는 않는다. **개편안(시험값)**에서는 야전 분대별로 원소 효과와 시너지 조건을 계산하며, 서로 다른 야전 분대의 원소를 한 조합으로 세지 않는다. 분대 역할을 강제 병종이나 전용 능력으로 바꾸지 않고, 플레이어가 배치한 원소 구성과 시너지에 따라 전선 유지·기동·견제 같은 운용 역할을 안내한다.

| 조합 | 반응 | 데이터상 발동 조건과 효과 |
| --- | --- | --- |
| 물 + 번개 | 감전 | 젖은 적에게 번개가 맞으면 번개 피해와 연쇄 범위가 늘어난다. |
| 물 + 얼음 | 빙결 | 젖음 상태의 적이 얼음 공격에 맞으면 공격 속도가 일정 시간 감소한다. |
| 물 + 불 | 증기 | 젖음 상태의 적이 불에 맞으면 일정 반경에 공격 사거리 감소 영역이 생긴다. |
| 불 + 바람 | 화염 확산 | 불이 적용한 화상이 바람 공격을 통해 주위 적에게 번진다. |
| 바람 + 흙 | 모래폭풍 | 같은 군단이 흙으로 먼저 맞힌 적에게 정해진 발동 시간 안에 바람이 맞히면 지속 피해와 사거리 감소 영역이 생긴다. |
| 연기 + 번개 | 플라즈마 폭발 | 연기 상태의 적에게 번개가 맞으면 범위 피해를 준다. |

반응 반경, 지속시간, 추가 피해와 같은 조절 값은 `gamedata.json`의 `reactions`에 둔다. 모래폭풍의 선행 적중 조건은 기획 주석에서 플레이테스트 확정 대상으로 표기돼 있다.

## 본진 및 시설

| 종류 | 표시 이름 | 전투·성장상 기능 |
| --- | --- | --- |
| 중심 거점 | 원시핵 | 플레이어의 본진이다. 파괴되면 플레이어가 패배한다. |
| 자원 시설 | 포집기 | 주변 원소 핵을 모아 건설·양성 재원을 지원한다. |
| 자연 양성 시설 | 응집로 | 핵을 써서 자연 원소를 양성한다. |
| 에너지 양성 시설 | 점화로 | 해금 뒤 핵을 써서 에너지 원소를 양성한다. |
| 자동 방어 | 수호 위성 | 건설 때 탑재한 원소를 유지하며 가장 가까운 공격 가능한 대상을 공격한다. 이동하거나 탑재 원소를 보충하지 않는다. |
| 본진 방어 | 자기권 | 본진을 감싸며 본진 피해를 먼저 흡수한다. |

레벨 해금, 건물 체력·범위·건설 시간, 수호 위성 슬롯 상한 등은 `gamedata.json`의 `baseLevels`, `buildings`, `towers` 값으로 관리한다. 현재 콘텐츠 외형 원칙은 [아트 방향](./11-art-audio.md)을 따른다.

### 개편안 (시험값)

신규 모드 **근원 쟁탈전**은 중앙 관문 세 곳을 공개 점령 목표로 추가한다. 관문은 공격 가능한 시설이 아니며, 입장한 분대와 해당 시점에 공개 가능한 점령 상태만 판정·표시한다. 관문 점령 인원과 승리 조건은 [시스템 기획](03-systems.md#근원-쟁탈전의-경기-흐름), 배치 위치와 경로는 [레벨디자인](06-level-design.md)에 둔다.

본진이 처음 무력화된 뒤 자동 재점화되는 규칙은 패배 뒤에도 관문 경쟁에 복귀할 기회를 제공한다. 이를 새로운 건물이나 원소 종류로 세지 않는다. 야전 분대는 별도 능력을 가진 콘텐츠가 아니라 현재 14종 원소를 여러 묶음으로 편성하는 운용 단위다. 신규 역할별 수치나 효과는 추가하지 않으며, 시험값 수치는 [수치 밸런스](09-balance.md)에서 관리한다.

## 중립 및 맵 자원

중립 원소는 가까운 대상을 추적하고 공격한다. 대상이 추적 범위나 시야에서 벗어나면 원래 자리로 돌아간다. 처치 시 전향 확률이 높아 초반 성장의 주요 상대다. 무리는 전장에 분산하고 에너지 중립은 중앙에 둔다. [중립 배치](06-level-design.md) · [수치 원본](../../../shared/Data/gamedata.json)

원소 핵은 전장에 생성되거나 처치 결과로 떨어진다. 군단과 포집기가 주변 핵을 모으고, 플레이어는 양성과 건설에 사용한다. 판 밖 스킨·업적·칭호는 원본 구상으로 따로 관리한다. [경제·성장](08-economy-progression.md) · [라이브 운영](13-live-operations.md)
