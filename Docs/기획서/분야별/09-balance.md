## 개편안 시험값

아래 수치는 근원 쟁탈전용 시험값이다. 적용 단계에서는 `gamedata.json`의 모드별 항목에 두고 서버와 클라이언트가 같은 수치를 읽는지 검증한다. [현행 JSON](../../../shared/Data/gamedata.json)

### 전장과 승패 시험값

| 항목 | 개편안 |
| --- | --- |
| 인원·경기 시간 | 2~15인, 최대 12분. 8:00 예고, 9:00 관문 개방 |
| 전장 크기·이동 | 2인 기준 한 변 208m, 시작 인원에 비례해 면적을 늘리고 한 변을 8m 단위로 반올림. 이동 속도 7m/s |
| 관문 | 3곳, 반경 14m, 중심 간격 44m. 각 관문에 같은 야전 분대의 중심과 원소 6기 이상 |
| 승리와 마감 | 2곳 단독 점유를 15초 연속 유지. 12:00이면 현재 관문 수와 마지막 60초 점유 시간 순으로 비교 |

인구는 야전 세 분대와 수비대의 합이다. 대기 양성과 집결 중 증원은 해당 부대에 미리 할당한다. 다중 타격은 직접 표적을 제외한 추가 대상에 상한을 적용한다. 직접 표적이 없는 지속 영역은 매 피해 틱 최대 6기다. 기존 순서가 있는 효과는 그 순서를 쓰고, 범위 후보는 가까운 적부터 적용한다. 동거리에서는 ID 순으로 판정한다. [자원 흐름](08-economy-progression.md) · [원소 효과](04-content.md)

### 본진 방어 시험값

| 항목 | 개편안 |
| --- | --- |
| 본진·자기권 | 본진 체력 7,200, 자기권 체력 1,800. 본진을 직접 노린 구조 피해에만 ×0.30을 적용한다. 자기권 직접 공격은 일반 시설과 같은 규칙이다. |
| 본진 대상 피해 속도 | 배율 적용 뒤 자기권 흡수 전에 본진마다 피해 예산을 공유한다. 초당 600을 채우고 최대 300까지 저장하며 시작 시 300이다. 한 틱의 합계가 예산을 넘으면 초과분을 흡수한다. 공격자를 나눠도 예산은 같다. |
| 수비 공간·포집 | 수비대 이동과 건설은 본진 반경 24m. 포집기 수집 반경 20m, 자연·에너지 타워 사거리 8m |
| 경보와 귀환 | 본진 또는 본진 시설 첫 피해에서 경보, 같은 공성은 5초 간격 재알림. 야전 분대 귀환 3초, 성공 시 전 분대 공용 60초, 시전 중단·배치 실패 뒤 5초 재시도 제한 |
| 시작 보호와 재점화 | 초기 20초 본진·시설·수비대 PvP 보호. 첫 무력화 20초 뒤 본진 체력 60%로 자동 재점화. 재점화 시 소유 원소가 0기면 1번 분대에 주력 8기를 예약해 빈 집결점에 배치 |

만피 본진이 공격을 받으면 자기권을 빼고도 이상적인 연속 최대 피해 기준으로 약 **11.5초**가 필요하다. 계산은 `(7,200 − 300) ÷ 600`이다. 본진이 이전 피해를 입은 상황, 경보를 본 시점, 시전 취소와 귀환 위치는 별도 실측한다. [방어 상태와 명령](03-systems.md) · [검증](12-playtest.md)

### 역전과 격차

처치 직후 보상을 주면서 전향으로 얻는 병력은 짧은 구간마다 제한해 단일 전투에서 격차가 크게 벌어지는 일을 줄인다. 결전에서는 같은 분대의 중심과 생존 원소 6기가 관문 안에 들어가면 상대가 가진 한 곳을 경합으로 바꿀 수 있다. 큰 군단은 두 곳을 유지할 여유가 있고, 작은 군단은 우회해 한 곳을 끊는 선택을 할 수 있다. [역전 재현 시나리오](12-playtest.md#개편안의-구체-재현-시나리오)

## 상성, 방어, 순위

| 항목 | 현재 기준 | JSON 키 |
| --- | --- | --- |
| 같은 그룹 상성 | 유리 ×1.25, 불리 ×0.8. 그룹마다 상대 3종에 유리하고 3종에 불리하다. | `matchups`, `rings` |
| 교차 상성 | 에너지가 지정 자연 원소를 공격할 때 ×0.8. 다른 교차 공격은 ×1.0. | `matchups`, `crossCounters` |
| 중립과 전향 | 중립 공격력 ×0.6. 전향 시 본래 공격력과 최대 체력 100%로 합류한다. | `neutral`, `economy.convertedHealthRatio` |
| 본진 방어 | 본진 체력 2,000. 자기권은 체력 1,000만큼 본진 피해를 먼저 받는다. | `buildings.base`, `buildings.dome` |
| 타워 | 체력 500, 중심 사거리 6m. 같은 속성 원소의 공격 주기에 기본 피해 ×2를 사용한다. | `towers` |
| 접속 순위 | 본진을 제외한 완공 시설당 10점, 본진 레벨당 25점, 생존 원소당 2점, 전투 승리당 100점. | `score` |

상성 관계는 [원소 상성도](../Elemental%20Legion%20속성%20상성도.html)에서 확인한다. 공성 공격은 시설 표면까지의 거리, 타워는 중심까지의 거리를 사용한다. 원본은 번개·빛의 사거리와 자연 원소의 비용 대비 물량, 에너지 원소의 인구 슬롯당 성능을 서로 다른 강점으로 잡았다. [원본 전투 수치 기획](../Elemental%20Legion%20게임%20기획서.md#유닛타워-수치) · [공성 판정](../../../shared/Runtime/Sim/SiegeSystem.cs)

## 밸런스 확인 항목

- **방어 여유.** 본진을 처음 공격한 시점부터 방어자가 상황을 알아차리고 대응하기까지 걸린 시간, 수비대·타워·자기권이 버틴 시간과 남은 체력을 함께 기록한다.
- **군단 성장과 운용.** 현재 최대 인구는 50기다. 최대 인구 중 실제로 조작 중인 군단 수와 대기·집결 중인 수비대, 예약 인구를 따로 기록한다. 같은 비용과 같은 인구에서 자연·에너지 조합의 교전 결과를 각각 본다.
- **우세의 지속.** 전향·양성으로 늘어난 병력과 자원 격차, 첫 교전 이후 선두 변화, 열세에서 방어나 반격에 성공한 사례를 본다. 목표 교전 시간이나 역전율의 기준값은 미결이다. [플레이테스트](12-playtest.md)
