# UI·UX·온보딩 기획

[분야별 기획서](README.md)

2026-11-11 후속 UI·조작 개편은 [UI와 분대 단축키 구현 계획](../../Plans/2026-11-11-ui-controls.md)과 [시안 이미지 인덱스](../../Art/Concepts/2026-11-11-ui-index.md)를 함께 확인한다. 아래에는 현행 화면과 근원 쟁탈전의 별도 기획도 포함한다.

관측소 UI에서 방에 입장하고, 전장에서는 군단 이동과 기지 운영에 필요한 정보를 확인한다.

## 주요 화면과 사용 흐름

| 구간 | 현재 화면·기능 |
| --- | --- |
| 게임 진입 | 타이틀, 방 찾기, 방 만들기, 설정 |
| 입장 준비 | 방 제목·정원 설정, 참가자 명단, AI 난이도·원소 선택, 준비와 시작 |
| 본진 성장 | 자원과 인구 확인, 시설 건설, 원소 양성·예약 취소, 수비대 집결 |
| 전장 판단 | 원소 구성과 군단 상태 확인, 카메라 이동, 미니맵에서 현황 확인 |
| 정보 확인 | Tab 현황판, 순위, 플레이어 세부 상태, 상성표, 채팅 |
| 설정 | 음향·화면·효과·조작 키 변경 |
| 경기 이탈 | 연결 복구·재접속, 접속 중 패배 안내와 다시 시작 |

대기실은 참가자와 원소 선택을 중심으로 둔다. 전장 HUD는 상단에 자원·인구·본진 상태, 왼쪽 아래에 미니맵, 아래쪽에 분대 선택과 양자 이동을 배치한다. 오른쪽 아래 버튼으로 양성·병력·건설 창을 하나씩 연다. 양성·건설 창은 서버에서 받은 조건과 게임 데이터의 비용을 표시한다. 관리 창을 닫은 상태에서 전장의 건물이나 원소에 마우스를 올리면 소개를 볼 수 있고, 좌클릭하면 카드를 열어 둘 수 있다.

### 개편안 (시험값)

**근원 쟁탈전** HUD는 1~4번 분대 카드를 제공한다. 카드에는 선택 상태와 분대 인원, 목적지·상태를 구분해 보여 준다. 1~3번은 야전 분대, 4번은 본진 수비대다. 상단 전역 시간은 12분 제한을 표시하고 8:00 개방 예고 뒤 9:00 관문 개방을 알린다. 1~3번 선택 때 `G`는 지정한 수비대를 선택 분대로 보내고, 기본 출격량 4기와 가능한 수를 표시한다. 양성 항목은 목적 분대를 고르고 1~4기 묶음을 주문하며, 실제 자원·인구 여유량과 예약량을 표시한다. `R`은 선택 야전 분대의 귀환 시전과 취소·대기 상태를 보여 준다. `B`는 현재 선택을 보존하고 본진 카메라만 이동한다.

## 조작과 정보 전달

- 기본 `1`~`4`를 눌렀다 떼면 해당 분대를 선택하고 카메라를 옮긴다. `5`를 눌렀다 떼면 야전 1~3을 선택한다. 출발 분대 키를 누른 채 다른 분대 키를 누르면 최대 3기가 목적 분대로 걸어간다. 현재 선택과 카메라를 유지하며, HUD는 서버가 확정한 출발 인원을 표시한다.
- WASD와 방향키는 선택 분대를 이동한다. 전장과 미니맵에서 우클릭하거나 우드래그하면 선택 분대를 지정점으로 보낸다. 건설 배치 중 우클릭은 배치를 취소한다.
- 미니맵 좌클릭과 좌드래그는 카메라를 옮긴다. 미니맵에는 내 분대 1~4의 번호와 이동 중인 원소를 표시한다. `B`는 현재 선택을 유지하면서 본진을 비춘다. `G`는 병력 창에서 지정한 인원과 목적 분대로 수비대를 출격시킨다. 내 본진이 공격받으면 HUD와 미니맵에서 강조하고 소리로 알린다. `R`은 선택한 야전 분대 하나의 양자 이동을 시전한다. HUD는 시전·취소·실패 상태와 공유 대기시간을 표시한다.
- 군단을 따라가는 카메라는 미니맵에서 위치를 살필 수 있으며 화면 버튼으로 군단에 다시 맞출 수 있다. 미니맵은 미탐색 구역, 누적 탐색 기록, 현재 시야를 구별한다.
- 클라이언트는 서버가 허용한 적과 중립의 현재 관측 정보를 표시한다. 전역 순위에는 합산 점수를 보여 준다.
- 개편안에서 피격 경보는 내 본진 표지를 강조한다. 적 위치와 방향은 현재 시야에 맞춰 표시한다. 관문 위치·개방·경기 시간은 공개하며, 관문별 소유·경합은 해당 관문을 관측할 때 보여 준다. 봉인 시간은 자신의 진행만 표시한다.
- Tab을 누르는 동안 현황판을 본다. 자원 옆 현황 버튼으로 열면 돌아가기 또는 ESC로 닫는다. ESC는 채팅 작성, 건설 배치, 소개·관리 창에서 현재 동작을 먼저 닫는다. 전투 중 메뉴·현황·설정을 열면 입력이 차단되는 동안 서버에서 전투가 계속된다.
- 집결 안내에는 대기 중과 이동 중 수비대 수를 표시한다. 플레이어는 집결 도중 새 집결 명령을 내릴 수 있다.
- 패배 화면의 다시 시작 버튼은 방 목록으로 돌아간다. 거기서 서버나 방을 선택해 새 입장을 시작한다.

## 처음 익히는 순서

현재 온보딩은 시작 원소를 고른 뒤 탐색으로 핵과 중립을 찾고, 시설 건설·양성·집결을 익히는 흐름이다. 원본은 AI전으로 학습하는 방향을 잡았다. 현재 방에 AI를 추가해 연습할 수 있으며, 단계별 첫 경기 안내는 미결이다.

**개편안(시험값)**의 첫 30초 안내는 한 번에 세 동작을 익히게 한다. 양성 묶음과 목적 분대를 고르고, 키 또는 우클릭으로 이동한 뒤 첫 자원·전향 보상을 확인한다. 이후 분대 카드와 본진 경보를 짧게 소개하고 9:00 관문 목표를 예고한다. 경기 결과에는 같은 모드 재경기 버튼을 두어 바로 다음 경기를 시작할 수 있게 한다. [원본 온보딩](../Elemental%20Legion%20게임%20기획서.md#진행온보딩아트) · [모드](05-modes.md)

## 본진 방어 피드백

원본 기획은 본진을 항상 알리고, 화면 밖 표시와 미니맵 표시, 공격 경보를 두는 구상을 담고 있다. 본진을 비운 사이의 공격을 핵심 긴장으로 둔다는 설명도 포함한다. 별도로 귀환 키와 피격 시 취소되는 짧은 시전의 본진 복귀 행동이 제안돼 있다.

현재는 군단 이동과 G 집결, 군단을 따라가는 카메라 버튼을 제공한다. 화면 밖에서 본진을 찾고 피격을 알아차리는 데 걸리는 시간, 그다음 방어 조작으로 연결되는 과정은 실제 플레이에서 확인할 항목이다. [기본 조작](../../../client/Assets/_Project/Scripts/Runtime/Input/ControlBindings.cs) · [본진 습격 시나리오](12-playtest.md#플레이-피드백을-확인할-시나리오)

**개편안**에서는 본진 또는 본진 시설의 첫 피해를 즉시 자기 HUD·미니맵·소리로 알리고 같은 공성의 반복 알림은 5초 간격으로 제한한다. 방어 HUD에는 본진 체력, 수비대 인원, 귀환 상태를 보여 준다. 시전 중단·배치 실패의 재시도 대기시간, 보호·무력화·재점화의 남은 시간을 표시한다. 집결점이 막혀 지원 8기가 대기하면 예약 인구와 상태를 안내한다.

## 검증 현황과 남은 확인

[UI 재구성 기록](../../Reports/2026-11-05-ui-reconstruction.md)에는 타이틀, 방 목록·방 만들기, 15명 대기실, 설정, 현황, ESC, 패배, 건설, HUD의 화면 경계 렌더링 검증이 기록돼 있다. 건물 설명과 양성 버튼은 회귀 테스트 범위에 있다.

전장 HUD와 단축키 개편의 Editor 컴파일·테스트·렌더링 결과는 [2026-11-11 구현 보고서](../../Reports/2026-11-11-ui-controls.md)에 기록했다. 실제 Play에서 마우스·키보드 포커스, 전투 중 양성·건설·집결·채팅, 접속 복구를 연결한 사용 흐름은 확인이 남아 있다. 근원 쟁탈전의 관문과 재경기는 해당 모드의 기획에서 다룬다.

현재 UI 세부 동작은 [README](../../../README.md#방-만들기와-접속)와 [게임 규칙](../../Rules/gameplay.md)을 기준으로 한다. 화면의 이름과 설명 표기는 [세계관·서사 기획](07-world-narrative.md) 및 [시설 원소 카탈로그](04-content.md)를 함께 확인한다.
