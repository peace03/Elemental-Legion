# Elemental Legion 분야별 기획서

2026-11-06 기준. **일반 상시 월드의 개편 제안**은 [메인 게임 개선안](../2026-11-06-main-world-improvement.md)에 있다. 아래의 **근원 쟁탈전**은 보류 중인 별도 모드 후보다. 분야별 문서는 현재 기준과 이 별도 모드의 시험안을 구분해 보관한다.

근원 쟁탈전은 세 야전 분대와 본진 수비대를 지휘해 최대 12분 동안 경쟁하는 개인전이다. 마지막 단계에서는 관문 두 곳을 지키거나 상대가 비운 관문을 노린다.

## 보류된 근원 쟁탈전 요약

| 플레이 피드백 | 개편안 | 규칙 문서 |
| --- | --- | --- |
| 본진이 멀고 습격을 받으면 대처하기 어렵다 | 피격 즉시 전용 경보. 본진 시점 전환, 수비대 직접 배치, 야전 분대 3초 귀환. 공성 피해 속도를 제한하고 첫 무력화 후 한 번 재점화한다. | [시스템](03-systems.md) · [레벨 디자인](06-level-design.md) |
| 더 많은 원소를 배치하고 제어하고 싶다 | 32기로 시작한다. 야전 3분대와 수비대를 따로 움직이고, 1~4기씩 양성해 원하는 분대를 보강한다. 최대 인구 목표는 200기다. | [시스템](03-systems.md) · [경제·성장](08-economy-progression.md) · [수치 밸런스](09-balance.md) |
| 끝까지 승부가 남았으면 좋겠다 | 9분에 관문 세 곳이 열린다. 그중 두 곳을 15초 연속 단독 점유하면 승리한다. 12분에는 현재 관문과 마지막 60초 점유 기록으로 승부를 가린다. | [모드·승패](05-modes.md) · [플레이테스트](12-playtest.md) |

## 기준과 상태 표기

- **기획 의도**는 원본에 담긴 목표와 설정이다. 원본의 확정·제안·임시 표기를 따른다. [원본 게임 기획서](../Elemental%20Legion%20게임%20기획서.md)
- **현재 기준**은 작업공간의 규칙·코드·설정으로 확인되는 동작과 값이다. 수치를 편집할 때는 JSON을 사용한다. `_meta.placeholderPaths`에 포함된 값은 플레이테스트로 조정할 임시값이다. [게임 규칙](../../Rules/gameplay.md) · [수치 원본](../../../shared/Data/gamedata.json)
- **개편안**은 이 폴더에서 보류 중인 근원 쟁탈전의 제안 규칙을 가리킨다. 모드 시험값은 [수치 밸런스](09-balance.md), 일반 상시 월드 시험값은 [메인 게임 개선안](../2026-11-06-main-world-improvement.md#레벨과-경제-시험값)에 둔다.
