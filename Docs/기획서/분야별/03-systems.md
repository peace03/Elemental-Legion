# 시스템 기획

[분야별 기획서](README.md)

서버는 군단 이동, 전투, 건설과 자원 상태를 판정한다. 클라이언트는 이동 방향과 행동 의도를 보내고 허용된 시야와 사건을 표시한다. [게임 규칙](../../Rules/gameplay.md) · [아키텍처 규칙](../../Rules/architecture.md)

## 군단 조작과 공간 규칙

| 규칙 | 현재 동작 |
| --- | --- |
| 조작 단위 | 방향키로 플레이어의 군단 중심을 이동한다. 플레이어는 모든 군단원을 함께 지휘한다. |
| 이동 속도 | 군단 속도는 `world.legionSpeed` 하나를 쓴다. 개별 원소의 이동 속도나 군단 규모별 감속은 없다. |
| 진형 | 근접 원소가 진행 방향 앞쪽, 원거리 원소가 뒤쪽에 배치된다. 같은 플레이어의 원소 사이에는 최소 간격을 둔다. |
| 진형 복귀 | 슬롯에서 멀어진 원소는 설정된 복귀 속도 배율로 따라잡는다. 건물을 만난 중심은 멈추며, 개별 원소는 건물 가장자리를 돌아 슬롯에 접근한다. |
| 자동 추적 | 이동 입력이 없으면 원소는 진형 이탈 범위 안의 적 유닛이나 공격 가능한 건물을 추적한다. 이동 중에도 이미 사거리 안에 든 표적은 공격한다. |
| 장애물 | 건물만 이동 장애물이다. 자연 지형의 통행 제한은 현재 핵심 규칙으로 정의되어 있지 않다. |
| 카메라·시야 | 카메라는 군단을 따르거나 다른 곳을 살펴볼 수 있다. 시야와 적 정보 공개 여부는 서버가 계산하며, 지난 탐색 상태는 미니맵에 저장한다. |

현재 조작 단위는 플레이어당 군단 중심 하나다. 인구는 본진 레벨별 `baseLevels[].populationCap`을 따르며, 양성 예약도 슬롯을 사용한다. [서버 명령 목록](../../../shared/Runtime/Sim/SimCommand.cs) · [인구 상한](08-economy-progression.md#본진-성장과-해금)

## 전투와 군단 성장

전투는 자동으로 진행된다. 원소는 공격 가능 범위에서 가까운 적을 표적으로 고르고, 군단 구성에 따라 속성 상성과 반응을 적용한다. 플레이어 소속 생명 원소는 가장 가까운 부상 아군을 회복한다. 중립 생명은 회복을 하지 않고 기본 공격을 한다. 수호 위성은 선택한 원소를 완공 뒤에도 유지하며 이동하지 않는다.

같은 그룹은 상성 고리의 다음 세 원소에 유리하고 앞의 세 원소에 불리하다. 그룹을 넘는 공격은 기본 배율을 쓰며, 에너지가 지정 자연 원소를 공격할 때만 피해가 줄어든다. 시너지는 같은 군단의 원소가 적에게 상태와 후속 타격을 이어 줄 때 발동한다. [원소와 시너지](04-content.md) · [상성 수치](09-balance.md)

처치한 유닛의 소유자가 전향 권리를 얻는다. 타워로 처치하거나 인구 상한에 걸린 적, 이미 전향한 적은 핵을 남긴다. 전향 유닛은 속성을 유지하고 체력과 상태를 초기화한 뒤 군단에 합류한다. 같은 틱에 사망한 유닛을 모두 인구에서 뺀 다음 전향을 적용한다. [경제·성장](08-economy-progression.md) · [전향 판정](../../../shared/Runtime/Sim/EconomySystem.cs)

## 건설과 본진 방어

본진 주변에 건물을 배치한다. 서버는 비용, 해금, 개수, 건설 범위와 점유를 검사하고 착공한다. 공사 중인 건물도 자리를 차지하고 공격받는다. 완공 시 시설 기능과 시야가 활성화된다. 공사 중 파괴되면 건설 비용은 소모된다. [게임 규칙](../../Rules/gameplay.md)

양성된 원소는 자동으로 군단에 합류하지 않는다. 수비대로 본진 부근에 대기하고, **집결**을 누를 때 존재하던 수비대가 설정된 이동 배율로 군단 중심을 향해 출발한다. 이동 중에도 전투한다. 새로 양성된 수비대는 다음 집결 명령까지 대기한다. UI는 집결 중인 수와 본진 대기 수를 표시한다.

본진에는 수비대와 수호 위성이 남아 자동 방어하고, 자기권이 건설돼 있으면 본진 피해를 먼저 흡수한다. 본진에서 멀리 나간 군단은 이동 입력으로 돌아온다. 집결로 출발시킨 수비대만큼 본진 대기 병력이 줄어든다.

## 개편안 (시험값)

근원 쟁탈전에 적용할 제안 규칙이다. 모드·맵·수치·UI의 상세 조건은 분야별 문서에 둔다. [모드 기획](05-modes.md) · [레벨 디자인](06-level-design.md) · [수치 밸런스](09-balance.md) · [UI·UX](10-ui-ux.md)

### 근원 쟁탈전의 경기 흐름

최대 12분의 2~15인 개인전이다. 9:00에 세 관문이 열리면 야전 분대가 관문을 점유한다. 관문은 공개 목표이며, 위치와 경기 시각을 모두가 알 수 있다. 점유 자격과 봉인·마감 판정은 [승패 조건](05-modes.md)을 따른다.

### 야전 분대와 원소 배치

플레이어는 서로 독립된 야전 분대 1~3번과 본진 수비대 4번을 운용한다. 시작 병력은 각 야전 분대 8기와 수비대 8기로 총 32기다. 목표 인구 상한은 야전 분대마다 60기, 수비대 20기로 총 200기다. 1~4번 키로 분대를 고른다. WASD 또는 방향키는 선택한 분대를 직접 이동시키며, 전장 우클릭은 지정점으로 보낸 뒤 대기와 자동 방어 상태로 둔다. 미니맵 클릭은 카메라 이동을 유지한다. `B`는 선택 상태를 보존한 채 본진 카메라만 보여 주고, 4번 수비대를 고르면 본진 카메라로 전환한다.

수비대는 본진 반경 24m 안에서만 배치·이동하고 경계 밖 적을 추적하지 않는다. 수비대는 타워와 함께 자동 전투한다. `G`는 선택한 야전 분대로 수비대 일부를 출격시키며, UI에서 지정한 수를 사용하고 기본값은 4기다. 서버는 생존 수, 분대 슬롯, 양성·출격 예약을 검사한다. 조건을 충족하지 못하면 이유를 안내한다. 출격한 원소는 이동해 분대에 닿아야 합류한다. 이동 중에는 교전과 손실이 가능하다. 야전 분대 전멸 시 그 분대에 배정되어 생존한 증원은 본진 집결점에 모여 해당 분대를 재구성한다.

양성은 1~3번 야전 분대 또는 4번 수비대로 보낸다. 기존 단일 대기열에서 1~4기를 주문하고 목적 분대의 인구 슬롯을 즉시 예약한다. 기본 묶음은 4기이며 자원·인구 여유로 가능한 수를 표시한다. 완성된 수비대는 본진에 배치하고, 야전 증원은 본진에서 출발해 합류한다. `G` 출격은 같은 유닛의 슬롯을 수비대에서 목적 분대로 한 번만 옮긴다. 야전 분대별로 진형·표적을 관리하고, 원소 시너지는 같은 야전 분대의 원소가 상태와 후속 타격을 이을 때 적용한다.

서버는 명령을 받은 참가자와 부대의 소유권, 이동 가능한 범위, 인구 예약을 확인한다. 빈 야전 분대의 이동은 증원으로 분대를 재구성한 뒤 받는다. 이 모드의 시야는 생존 소유 원소와 완공된 활성 시설에서 계산한다. 카메라·미니맵 이동은 표시할 지점을 고르는 조작이다. [보안 규칙](../../Rules/security.md) · [시야 표시](10-ui-ux.md)

### 본진 경보와 긴급 귀환

본진 또는 본진 시설이 처음 피해를 받는 즉시 소유자 HUD·미니맵·소리로 경보한다. 같은 본진 구역에서 피해가 이어지면 시설별 경보를 묶어 5초에 한 번까지 다시 알린다. 경보는 내 본진 표지를 강조한다. 공격자 위치와 방향은 이미 서버가 관측을 허용한 정보로만 표시한다. 방어 HUD에는 본진 체력, 수비대 수, 귀환 상태를 보여 준다.

`R`은 선택한 야전 분대의 합류 원소만 귀환시킨다. 한 번에 한 분대가 3초 동안 정지해 시전한다. 시전 중 분대가 적의 피해를 받거나 이동 명령을 수행하면 취소된다. 완료 틱에 서버가 활성 본진과 예약된 귀환 구역의 빈 슬롯을 다시 검사한다. 생존 분대원 전원이 들어갈 때 한꺼번에 배치하며, 공간이 부족하거나 본진이 무력화되면 시전을 끝내고 원래 위치를 유지한다. 성공 시 전 분대에 60초, 시전 중단·배치 실패 시 5초의 공유 대기시간을 적용한다. [귀환 구역](06-level-design.md#구역과-이동-경로)

경기 시작 후 20초 동안 본진·본진 시설·수비대를 다른 플레이어의 피해에서 보호한다. 이때 타워와 수비대의 대인 공격은 멈추고 야전 분대는 교전할 수 있다. 본진을 직접 노린 공성은 배율을 적용한 뒤 공격자 전체가 공유하는 본진 피해 예산을 쓴다. 초과분을 흡수한 다음 자기권과 본진에 피해를 적용한다. 자기권 직접 공격은 일반 시설 규칙을 쓴다. [방어 시험값](09-balance.md#본진-방어-시험값)

### 본진 무력화와 역전 기회

처음 본진 체력이 0이 되면 20초 동안 무력화한다. 포집·양성·신규 건설·업그레이드·귀환이 멈춘다. 대기 중 양성은 환불하고 이미 시작한 양성 비용은 소모하며 양성 예약 슬롯은 해제한다. 진행 중인 공사는 계속된다. 살아 있는 시설, 수비대, 야전 병력과 핵을 유지하며 타워와 수비대는 계속 싸운다. 20초 뒤 같은 본진이 최대 체력의 60%로 자동 재점화한다.

첫 재점화 틱에 생존 소유 원소가 0기면 주력 원소 8기를 1번 분대에 한 번 예약한다. 야전·수비대·합류 중 증원을 모두 생존 검사에 포함한다. 집결점에 8기의 유효 슬롯이 열리는 즉시 배치하고, 두 번째 무력화나 경기 종료 시 남은 예약을 해제한다. 두 번째 본진 무력화는 영구적이며 살아 있는 원소로 관문을 노릴 수 있다. [탈락과 복귀](05-modes.md#탈락과-복귀)

전향한 원소는 막타를 낸 합류 야전 분대나 수비대의 남은 슬롯을 사용한다. 수비대는 소유 본진 반경 안에서 쓰러진 원소를 전향시킨다. 타워나 이동 중 증원의 막타, 재전향, 인구·부대 슬롯 초과는 핵을 남긴다. PvP 전향 상한은 상대와 무관하게 전향을 얻는 소유자별로 공유한다. 본진 무력화는 탈락과 별도 상태여서 살아 있는 분대는 계속 전향할 수 있다. [전향 시험값](09-balance.md#성장과-전투-시험값)

## 기획과 현재 구현의 차이

| 주제 | 원본 기획 상태 | 현재 구현 근거와 확인할 내용 |
| --- | --- | --- |
| 본진 표시와 공격 경보 | 화면 밖 본진 표시와 미니맵 표시, 공격 경보 구상이 있다. | 서버는 내 본진과 시야 안 적 건물을 관측에 포함한다. 전용 피격 경보와 화면 가장자리 표시는 [UI 확인 항목](10-ui-ux.md#본진-방어-피드백)이다. |
| 본진 귀환·대시 | 시전 중 피격으로 취소되는 귀환을 제안했다. 대시는 선택 사항이다. | 데이터에 `legion.recall`·`legion.dash` 설정이 있고, 현재 조작은 이동과 집결을 사용한다. [서버 명령 목록](../../../shared/Runtime/Sim/SimCommand.cs) |
| 다중 분대·근원 쟁탈전 | 원본에는 1~3 야전 분대와 중앙 관문 경기 규칙이 없다. | 위 개편안은 시험 제안이다. 분대 지휘, 관문 판정, 본진 복구와 PvP 인구 규모는 구현·부하 검증이 필요하다. |

원본 구상은 [조작과 시야](../Elemental%20Legion%20게임%20기획서.md#조작과-시야)에 있다. 방어 대응과 군단 운용의 체감은 [플레이테스트](12-playtest.md)에서 확인한다.
