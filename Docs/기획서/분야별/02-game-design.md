## 개편안의 경기 흐름

| 경기 시간 | 플레이어가 고르는 행동 | 돌아오는 보상과 위험 |
| --- | --- | --- |
| 0:00~2:00 | 세 야전 분대 중 하나를 가까운 핵·중립으로 보낸다. 시작 응집로로 양성할 분대를 고르고 수비대를 둘 위치를 정한다. | 첫 15초 안에 핵·양성·전향 중 첫 보상을 경험하는 것이 목표다. |
| 2:00~8:00 | 안전한 본진 쪽과 공용 자원 길을 오간다. 분대를 나눠 교전·자원 수집·수비를 병행하고, 본진 성장과 원소 조합에 투자한다. | 교전에서 전향·핵을 얻는다. 여러 길을 차지하면 수급 기회가 늘고, 멀리 보낼수록 각 분대와 본진이 얇아진다. |
| 8:00~9:00 | 관문 개방 예고를 보고 분대 두 곳의 접근로를 고른다. 병력을 더 모을지, 먼저 길목을 잡을지 결정한다. | 가까운 관문 선점과 먼 쪽 우회가 서로 다른 기회를 준다. |
| 9:00~12:00 | 두 관문을 동시에 확보하거나 상대의 한 관문을 경합으로 바꾼다. 본진 습격과 결전 병력 투입 사이에서 판단한다. | 관문 2곳을 15초 연속 단독 점유하면 끝난다. 시간이 다하면 마감 시점의 점유가 우선이다. |
| 경기 종료 | 승리·무승부 사유와 내 전환점을 확인하고 재경기를 선택한다. | 같은 방에서 다시 준비한다. 이전 판의 자산과 우세는 새 판에 이어지지 않는다. |

| 공격·수비가 맞물리는 상황 | 개편안에서 가능한 행동 |
| --- | --- |
| 자원을 캐러 간 사이 본진에 첫 피해 | 피격 경보로 본진을 확인하고 수비대를 옮긴다. 전투에 묶이지 않은 야전 분대만 귀환시켜 다른 분대의 행동을 이어 간다. |
| 본진이 먼저 무력화 | 야전 병력으로 싸움을 이어 가며 첫 재점화를 기다린다. 상대는 양성과 수급을 끊은 사이 다른 목표로 이동할 수 있다. |
| 병력은 밀리지만 상대가 한쪽에 집중 | 최소 병력을 두 관문에 나눠 보내거나, 상대가 가진 관문 하나의 점유를 끊는다. 앞선 쪽은 두 곳을 동시에 지킬 때만 봉인을 유지한다. |

초반의 순위와 성장 차이는 병력·시설·위치의 이점으로 남는다. 승패 판정에는 관문 점유를 쓴다. [군단과 방어](03-systems.md) · [판정 순서](05-modes.md) · [경제](08-economy-progression.md)

## 한 번의 플레이 흐름

아래는 개편 전 현재 기준이다.

| 단계 | 플레이어가 하는 일 | 관련 기획 |
| --- | --- | --- |
| 입장 | 방 또는 서버를 선택하고 자연 원소를 고른다. 일반 입장은 1레벨 본진, 같은 자연 원소 3기, 핵 0개에서 시작한다. | [모드·승패](05-modes.md) · [UI·온보딩](10-ui-ux.md) |
| 탐색 | 군단 중심점을 움직인다. 시작 구역의 자연 중립 무리와 맵 핵을 찾고, 적이 보이면 상성·거리·군단 규모를 비교한다. | [시스템](03-systems.md) · [레벨 디자인](06-level-design.md) |
| 초반 성장 | 적을 쓰러뜨려 전향 또는 핵을 얻고, 모은 핵을 포집기·응집로·타워에 투자한다. 양성된 원소는 수비대로 대기하며 집결로 군단에 합류한다. | [경제·성장](08-economy-progression.md) · [수치 밸런스](09-balance.md) |
| 구성 확장 | 다른 원소를 전향·양성해 시너지를 노린다. 본진 업그레이드로 인구 상한을 늘리고 점화로를 열어 에너지 원소를 양성한다. | [콘텐츠](04-content.md) · [경제·성장](08-economy-progression.md) |
| 공성·수비 | 원정 군단으로 적 본진을 압박한다. 자기 본진 주변에서는 수비대·타워가 자동으로 싸우고, 건설한 자기권이 본진 피해를 먼저 흡수한다. | [시스템](03-systems.md) · [레벨 디자인](06-level-design.md) |
| 패배·재입장 | 본진이 파괴되면 개인 플레이가 끝난다. 결과 화면에서 방 목록으로 돌아가 새 입장을 시작할 수 있다. 최후 생존 승리는 AI가 포함된 방의 규칙이다. | [모드·승패](05-modes.md) |

## 플레이 중 일어나는 판단

- 주력 원소는 양성 비용과 시간이 줄어든다. 전향한 원소는 원래 속성을 유지하므로, 군단을 섞으면 처음 고른 원소 밖의 상성과 시너지를 활용할 수 있다. [콘텐츠](04-content.md) · [수치 밸런스](09-balance.md)
- 공성으로 상대를 패배시키는 동안 내 수비는 본진 주변 자산에 달려 있다. 수비대를 집결시키면 원정 병력은 늘지만 본진에 대기하던 원소가 줄어든다. [시스템](03-systems.md)
- 전장 화면의 지형은 카메라로 둘러볼 수 있다. 적·중립 유닛과 적 시설은 서버의 관측에 따라 표시되므로 상대 군단의 규모와 위치를 파악하려면 정찰해야 한다. [레벨 디자인](06-level-design.md) · [UI·온보딩](10-ui-ux.md)
- 원소 형태와 효과는 속성을, 발밑 링과 소유자 색은 소속을 구분한다. 설정에서는 전향을 강착, 새 입장을 재탄생으로 설명한다. [세계관](07-world-narrative.md) · [아트·사운드](11-art-audio.md)

게임 판정과 시야는 서버가 맡고, 클라이언트는 조작 명령을 보낸다. 게임 수치는 공유 JSON에 모은다. 저장·복귀와 운영 조건, 기존 검증의 범위는 별도 문서에서 관리한다. [아키텍처 규칙](../../Rules/architecture.md) · [라이브 운영](13-live-operations.md) · [플레이테스트](12-playtest.md)
