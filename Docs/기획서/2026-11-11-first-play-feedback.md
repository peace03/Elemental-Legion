# 첫 플레이에서 행동과 결과를 읽는 화면

2026-11-11 · 메인 게임 개선 제안 · 의사결정 패널 종합

**추천안은 처음 행동할 곳에 짧은 조작 표시를 붙이고, 실제 결과가 생기면 전장과 관련 HUD를 함께 바꾸는 방식이다.** 플레이어가 가까운 핵을 발견해 선택 분대를 보내면 목적지 표시가 생긴다. 본인이 핵을 얻었을 때는 같은 핵 아이콘이 그 자리와 잔고 옆에 표시된다. 첫 이동에서 배운 표현을 양성·분대 지원·본진 방어에도 반복한다.

현재 HUD는 상단 문장으로 첫 보상, 자연 양성소, 양성·증원, 귀환 연습을 안내한다. 기존 Editor 캡처에서 전장과 하단 조작 영역의 배치를 확인했다. 초행자가 실제로 어디서 멈추는지는 사람 플레이에서 확인할 항목이다. [현재 안내 코드](../../client/Assets/_Project/Scripts/Runtime/UI/CombatHud.Guidance.cs) · [HUD 구현 보고서와 캡처](../Reports/2026-11-11-ui-controls.md)

## 첫 판에서 플레이어가 보는 장면

| 상황 | 화면과 입력 | 확인되는 결과 |
| --- | --- | --- |
| 처음 입장 | 선택한 `1`의 번호를 전장·분대 카드·미니맵에서 맞춘다. 처음 이동하기 전에는 선택 분대 가까이에 마우스 그림과 `바닥 우클릭 · 이동`을 붙인다. 현재 시야의 가까운 핵 하나는 `◇ 핵 · 접근하면 획득`으로 표시한다. | 우클릭한 곳에 속 빈 표식과 `이동 요청`이 나타난다. 서버가 같은 명령을 반영하면 실제 목적지 표식으로 바뀐다. 이동과 도착은 분대의 서버 상태를 읽는다. |
| 핵·중립을 만남 | 야전 분대로 핵에 접근하거나, 가리킨 중립의 `사거리 안 자동 교전`을 읽고 다가간다. 핵과 중립은 아이콘 모양으로 구별한다. | 본인의 핵 획득이 확정되면 `◇ +N`과 잔고 증가를 함께 보여 준다. 내가 전향시킨 중립은 아군 표식으로 바뀌고, 합류하면 해당 분대의 인원이 갱신된다. |
| 첫 투자 | 건설 창의 포집기·응집로·수호 위성에 각각 `핵 수급`, `병력 양성`, `본진 방어`를 적는다. 현재 비용과 잠금 이유를 선택 항목에서 읽는다. | 배치 예상 테두리가 서버 착공 뒤 건설 중 표식으로 바뀌고, 완공하면 시설 외형이 드러난다. 양성 창은 비용·수량·목적 분대를 보여 주고 예약·진행·완료를 갱신한다. |
| 분대 지원 | 기존 병력 창에서 수비대 집결의 출발과 목적을 읽고 버튼으로 보낸다. 숫자키 조합은 분대 버튼에서 함께 발견할 수 있게 한다. 예를 들어 `4 → 2`는 최대 3기의 빠른 전송이다. | 서버가 2기를 출발시켰다면 `4 → 2 · 2기 출격`을 보여 준다. 미니맵 점은 실제 이동, 2번 카드의 증원 수는 해당 분대로 이동 중인 수다. 도착한 병력은 합류 인원에 반영한다. |
| 본진 구역 피격 | 실제 피해가 들어오면 본진 체력 표시와 미니맵의 내 본진에 경고 모양을 붙인다. `본진 보기 [B]`로 시점을 옮기고 `4 수비대`를 조종하거나, 야전 분대 하나를 선택해 `양자 이동 [R]`을 쓴다. | B를 눌러도 선택한 분대는 유지된다. 양자 이동 버튼 가까이에서 시전·귀환 성공·중단·실패·공유 대기를 읽는다. 경보는 서버가 알려 준 내 피격 시설의 위치를 사용한다. |

이 표는 안내가 나타나는 상황의 예시다. 플레이어는 보이는 핵과 중립 중 원하는 대상을 선택하고, 시설을 고르거나 다른 분대를 움직일 수 있다. 첫 화면에 보이는 대상이 없으면 선택 분대의 이동 표시와 미니맵의 탐색 경계를 남긴다. [메인 게임의 초반과 방어](2026-11-06-main-world-improvement.md) · [UI와 조작 기준](../Plans/2026-11-11-ui-controls.md)

## 표시의 우선순위와 정확성

- 전장에 덧붙이는 학습 표식의 첫 시험 상한은 **선택 분대 한 곳과 관련 대상 한 곳**이다. 표식은 입력을 가로채지 않는다. 전투 효과와 겹치면 짧은 설명을 해당 HUD나 열린 관리 창에서 읽게 한다. 피격 경보는 본진 HUD와 미니맵의 고정 위치에 우선 표시한다.
- 핵을 다른 사람이 가져가거나 시야에서 놓치면 대상 안내를 걷는다. 본인의 획득 사건이 확인됐을 때만 증가량을 표시한다. 빈 분대는 `합류 0기`로 보여 주고, 지원의 목적지로는 고를 수 있다.
- 이동 요청은 자기 분대의 명령 순번과 실제 목적지로 대조한다. 서버가 목적지를 보정하면 표시도 그 위치로 옮긴다. 별도 막힘 사유가 없으면 관측에 맞춰 `이동 지연` 또는 `확인 중`을 표시한다. 재접속·승계 때는 미확정 표식과 요청을 정리하고 새 관측으로 갱신한다.
- 착공과 빠른 전송의 출발 수는 실행 결과, 양성은 서버 대기열과 진행 상태, 합류는 목적 분대의 관측 인원으로 확인한다. 미니맵의 개별 이동 점은 현재 보이는 움직임을, 목적 분대 번호의 증원 수는 분대별 집계를 표현한다. 수비대로 양성한 원소는 본진 수비대 인원에 반영한다. [서버 사건과 관측](../protocol.md)
- 조작 안내를 끄면 처음 보여 주는 행동 문구를 숨긴다. 결과·거절·위험 표시는 남긴다. 동작 줄이기에서는 고정 윤곽·번호·짧은 상태명으로 읽고, 경보음은 시각 표시를 보완한다. [Xbox 접근성 지침 103](https://learn.microsoft.com/en-us/gaming/accessibility/xbox-accessibility-guidelines/103) · [Xbox 접근성 지침 114](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/114)

## 처음 만들 범위와 확인 기준

1. 첫 시제품은 **선택 분대 번호 → 우클릭 요청·반영 → 내 첫 핵 획득**에 집중한다. 핵을 다른 플레이어가 먼저 얻은 경우, 가려져 사라지는 경우, 명령 덮어쓰기와 연결 중단도 재현한다.
2. 현행 화면과 시제품을 처음 보는 사람을 각각 6명씩 배정하는 작은 비교를 제안한다. 같은 시작 조건과 해상도에서 조작 설명 없이 시작한다. 시제품의 첫 시험 목표는 6명 중 5명 이상이 60초 안에 이동하고 120초 안에 자신의 첫 보상을 알아보는 것이다. 첫 행동까지 걸린 시간, 실제 획득을 알아본 시점, 요청을 성공으로 오해한 횟수를 두 화면에서 같은 방식으로 기록한다. 인원과 시간은 시제품 평가용 시험값이다.
3. 후속 시험은 시설의 역할 선택, 양성 예약과 실제 합류의 차이, 키를 외우기 전 지원 버튼 발견, 본진 피격 후 보기·수비·귀환 중 첫 행동을 본다. 720p·UI 110%에서 병력이 겹칠 때와 무음·동작 줄이기에서도 같은 상태를 읽는지 확인한다.
4. 밀집 전장에서 같은 카메라와 관측을 써 표식 겹침, 입력 관통, 프레임 시간과 할당을 비교한다. 기존 Editor 캡처와 테스트는 화면 배치와 동작 구현의 근거다. 초행자의 이해와 개선안의 실전 가독성은 사람 시험에서 판단한다.
