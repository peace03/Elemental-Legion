# 첫 플레이 UX — 전장에서 발견하고 결과를 확인한다

2026-11-11 · 메인 게임 · 개편안

[첫 플레이 화면 시안 7장](../Art/Concepts/2026-11-11-first-play-ux-index.md) · [구현 계획](../Plans/2026-11-11-first-play-ux.md)

처음 접속한 플레이어가 전장의 병력과 자원을 보고 **무엇을 할 수 있는지, 누르면 무엇이 일어났는지** 알아차리게 한다. 첫 장면에서는 내 1번 분대를 확인하고, 바닥을 우클릭해 가까운 핵으로 이동한다. 분대가 움직이면 목적지에, 핵을 얻으면 획득 지점과 잔고에 결과가 나타난다. 양성·지원·귀환도 입력한 자리에서 진행 상태를 읽고 전장에서 결과를 확인하게 한다.

현재 HUD는 화면 상단의 안내 문장으로 보상 획득, 자연 양성소 건설, 증원 확인, 귀환 연습을 순서대로 제안한다. 개편안에서는 이 안내가 맡던 역할을 상황에 맞는 전장 표식과 기존 버튼으로 옮긴다. 플레이어는 핵 탐색, 중립 교전, 본진 방어 중 원하는 행동을 시작할 수 있다. ## 화면 배치

**개편안 · 기존 HUD에 얹는 표시.** 인용된 문구와 숫자는 화면 예시다. 잔고, 수량, 시간, 현재 키는 게임 상태와 사용자 설정에서 읽는다. [현재 HUD와 캡처](../Reports/2026-11-11-ui-controls.md)

| 화면 위치 | 플레이어가 보는 예시 |
| --- | --- |
| 전장 | 선택 분대의 받침과 번호 `1`, 그 옆에 `바닥 우클릭 · 이동`. 현재 시야의 가까운 핵 하나에는 `◇ 핵 · 야전 병력이 접근하면 획득`. |
| 왼쪽 위 자원 | `◇ 핵` 잔고와 획득 순간의 `+N`. 다른 획득·지출이 동시에 생겨도 잔고는 서버가 알려 준 값을 표시한다. |
| 오른쪽 위 본진 | 본진 체력과 `본진 보기 [B]`. 피격 때 같은 자리에 `! 본진 구역 피격`을 붙인다. |
| 왼쪽 아래 미니맵 | 내 분대 번호 `1–4`, 이동 중인 원소의 점, 경보 중 내 본진의 `!`. 지도를 가리키면 `좌클릭 보기 · 우클릭 이동`을 확인할 수 있다. |
| 아래 가운데 분대 | `1–4`는 각각의 분대, `5`는 전체 야전 선택. 선택한 카드에 합류·증원 인원을 표시하고 `양자 이동 [R]` 옆에 시전 상태를 붙인다. |
| 오른쪽 아래 관리 | `양성 · 병력 · 건설` 중 하나를 열고, 관련 비용·수량·진행·실패는 그 창의 해당 항목에서 읽는다. |

## 장면 1 · 처음 움직여서 핵을 얻는다

1. **어느 병력을 조작하는지 본다.** 같은 `1`을 전장, 하단 카드, 미니맵에서 강조한다. 분대에 합류 인원이 있고 화면에서 움직일 수 있을 때 `바닥 우클릭 · 이동`을 붙인다. 서버에 첫 이동이 반영되면 첫 안내를 접는다. 이후 같은 조작은 분대 카드나 미니맵을 가리켜 확인할 수 있다. 화면 밖 분대를 보려면 해당 숫자키를 눌렀다 떼거나 기존 `군단 중심`을 사용한다.
2. **클릭이 전달됐는지 본다.** 우클릭한 자리에 속 빈 고리와 `이동 요청`이 뜬다. 서버가 같은 분대의 지점 이동을 반영하면 실제 목적지에 실선 고리를 표시한다. 분대 중심이 움직일 때 `이동 중`, 실제 목적지에 도착하면 짧게 `도착`을 보여 준다. 방향키 이동에는 목적지 고리를 띄우지 않는다.
3. **보상을 어디서 얻었는지 본다.** 내 획득 사건을 수신하면 잔고 옆에 `◇ +N`을 표시한다. 획득 지점이 화면 안의 현재 시야에 있으면 그 자리에도 같은 표시를 띄운다. 핵을 놓쳤거나 내 획득을 확인할 수 없으면 대상 안내를 걷고 서버 잔고를 표시한다. 가까운 대상이 없으면 이동 조작만 읽을 수 있다. 빈 분대에는 `합류 0기 · 병력 창에서 지원`, 수비대에는 `본진 안에서 이동`을 표시한다.

~~~mermaid
flowchart LR
    accTitle: 우클릭에서 분대 도착까지
    accDescr: 우클릭 직후 속 빈 고리로 요청을 알린다. 서버가 같은 명령을 반영하면 실제 목적지를 표시한다. 분대 중심이 도착하면 도착으로, 실패가 확인되면 사유로 표시한다.
    A["바닥 우클릭"] --> B["속 빈 고리 · 이동 요청"]
    B -->|"같은 명령이 관측됨"| C["실선 고리 · 실제 목적지"]
    C -->|"분대 중심 도착"| D["도착"]
    B -->|"거절 확인"| E["해당 명령의 거절 사유"]
~~~

응답을 기다릴 때는 `이동 확인 중`, 목적지가 반영된 뒤 움직임이 지연될 때는 `이동 지연`을 표시한다. 막힌 이유는 확인된 경우에만 쓴다. 새 이동·정지 명령은 이전 요청과 표식을 대체한다. 건설 배치 중 우클릭은 `배치 취소`로 처리한다. 재접속이나 방 승계 뒤에는 새 서버 관측으로 표시를 복구한다. [분대 이동 규칙](../Rules/gameplay.md) · [명령과 관측](../protocol.md)

**중립을 먼저 발견한 경우.** 가리킨 중립의 표식에 `중립 · 사거리 안 자동 교전`을 붙인다. 확보할 후보가 실제로 생기면 후보와 확보 진행을 표시한다. 전향하면 아군 표식으로 바뀌고, 정식 분대에 합류하면 그 분대의 합류 인원을 갱신한다. 핵이 떨어진 경우에는 전장에 핵 아이콘을 표시하고, 획득 표시에는 같은 획득 조건을 적용한다. [자동 공격과 전향](../Rules/gameplay.md)

## 장면 2 · 핵으로 투자하고 병력을 보낸다

| 플레이어의 선택 | 누르기 전에 읽는 정보 | 행동 뒤 확인할 결과 |
| --- | --- | --- |
| **시설 고르기** | `포집기 · 핵 수급`, `응집로 · 자연 원소 양성`, `수호 위성 · 본진 방어`. 비용이나 잠금 이유는 시설 이름 옆에 붙인다. 살 수 있는 시설이 처음 생기면 기존 `건설` 버튼을 한 번 강조한다. | 기존 건설 미리보기에서 시설 윤곽과 확인 가능한 배치 제한을 읽는다. 배치를 누르면 `배치 요청`, 착공을 확인하면 `건설 중`, 완공하면 시설 외형과 사용 가능한 기능을 보여 준다. |
| **원소 양성** | 원소·수량·목적·총 비용을 실행 버튼 옆 한 줄에서 확인한다. 예를 들어 주력이 물이면 `물 1기 · 8핵 → 4번 수비대`다. | 서버 대기열에서 `예약 → 양성 중 → 출생`을 읽는다. 4번으로 보냈다면 수비대 인원, 2번으로 보냈다면 `2번 · 이동 중`을 먼저 보고 도착 뒤 합류 인원이 늘어난다. |
| **마우스로 지원 보내기** | 병력 창을 열면 `4 수비대 → 2번 · 1기 보내기 [G]`를 바로 볼 수 있다. 목적 야전 분대 1–3은 그 자리에서 선택한다. 수량은 기존 기본 1기와 `재편`에서 지정한 수량을 사용한다. | 버튼과 G는 표시된 목적과 수량으로 같은 집결 명령을 보낸다. 보낼 수비대가 부족하면 버튼 옆에서 읽는다. 출발 뒤에는 목적 분대에 실제 이동 중 인원과 합류 인원이 각각 표시된다. |
| **숫자키로 빠르게 보내기** | 분대 카드에서 `4를 누른 채 2 · 최대 3기 전송`을 확인한다. 단독으로 눌렀다 떼면 해당 분대를 선택하고 화면을 옮긴다. | 출발 분대에 2기만 있었고 서버가 둘을 출발시키면 `4 → 2 · 2기 출발`을 표시한다. 카메라와 현재 선택은 유지한다. 목적이 4번이고 받을 자리가 부족하면 사유를 표시한다. |

숫자키 전송은 서로 다른 1–4번 사이에서 쓴다. `5`는 전체 야전 선택이다. 미니맵 점의 밝기 변화는 개별 원소가 움직인다는 뜻이다. 목적 분대 번호와 카드의 `증원 N기`는 그 분대로 이동 중인 병력 수다. 이동 중 병력을 잃으면 증원 수가 줄어들고 합류 수는 실제 도착만큼 갱신된다. [현재 조작과 미니맵 기준](../Plans/2026-11-11-ui-controls.md) · [비용과 시설 데이터](../../shared/Data/gamedata.json)

## 장면 3 · 전장에 나가 있다가 본진을 지킨다

- **피격을 발견한다.** 실제 피해를 받으면 본진 체력 옆과 미니맵의 내 본진에 같은 `!`를 표시한다. `본진 구역 피격 · 본진 보기 [B]`는 양성·병력·건설 창을 연 상태에서도 읽힌다. 피격 시설에는 서버가 알려 준 피해 위치를 사용하고, 공격자는 현재 시야에서 확인할 수 있는 정보만 표시한다. 경보가 끝나면 강조가 기본 상태로 돌아간다.
- **본진을 보고 수비대를 움직인다.** B를 누르거나 경보 옆 버튼을 클릭하면 본진이 보인다. 선택 분대는 그대로 표시되므로, 이어서 `4 수비대`를 선택하면 바로 수비대를 조종할 수 있다.
- **선택한 야전 분대를 귀환시킨다.** 합류 병력이 있는 야전 분대 하나를 선택하면 버튼에 `1번 · 양자 이동 [R] · 3초 시전`처럼 표시한다. 사용할 수 없는 상태에서는 `야전 분대 하나 선택`, `합류 병력 필요`, `공유 대기 N초` 중 해당 사유를 보여 준다. 시전을 요청하면 `귀환 요청`을 표시하고, 서버가 시전을 시작하면 분대 발밑의 양자 고리와 버튼의 진행 표시가 함께 나타난다. 귀환이 확인되면 본진에 같은 고리가 짧게 나타나고 `귀환 완료 · 공유 대기 60초`로 바뀐다. 분대 번호와 소속은 유지된다. 이동·피격·시전 분대에서 병력 전송 등으로 중단되거나 본진의 배치 공간이 부족하면 `귀환 중단`과 확인된 이유를 보여 준다. [양자 이동 규칙](../Rules/gameplay.md) · [본진 피격·시전 응답](../protocol.md)

## 한눈에 읽히는 조건

- 전장에 붙는 첫 조작 문구는 **선택 분대 하나와 현재 관련 대상 하나**를 상한으로 시험한다. 분대가 겹치면 선택 번호를 우선 표시하고, 짧은 설명은 관련 HUD에서도 읽을 수 있게 한다. 전장 표식은 클릭을 가로채지 않는다.
- 경보와 현재 입력의 실패를 먼저 읽게 한다. 같은 종류의 반복 피격은 본진 경보 한 곳에서 갱신한다. 보상·이동·합류는 관련 위치와 버튼에 남겨 가운데 전장을 가리는 알림을 줄인다.
- 색이나 소리에 의존하지 않고 `속 빈 고리 + 요청`, `번호 + 선택 윤곽`, `! + 피격`으로 구별한다. `UI 동작 줄이기`에서는 점의 밝기 변화나 양자 고리의 애니메이션을 정적 점·윤곽과 문구로 바꾼다. `조작 안내`를 끄면 처음 뜨는 학습 문구만 숨긴다. [Xbox의 시각·청각 피드백 기준](https://learn.microsoft.com/en-us/gaming/accessibility/xbox-accessibility-guidelines/103) · [동작 접근성 기준](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/114)

## 첫 시제품에서 확인할 것

먼저 **선택 확인 → 이동 요청과 반영 → 내 핵 획득 확인**을 시험한다. 현행 화면과 개편 화면에 초행자 6명씩을 배정하고 같은 시작 위치·시야·조작 설정에서 설명 없이 시작한다. 개편 화면의 첫 시험 목표는 6명 중 5명 이상이 60초 안에 분대를 움직이고 120초 안에 자신의 첫 핵 획득을 알아보는 것이다. 행동 시간과 요청을 성공으로 오해한 경우를 함께 기록한다. 인원과 시간은 시험값이다.

| 확인할 장면 | 플레이어가 설명할 수 있어야 하는 결과 |
| --- | --- |
| 다른 플레이어가 핵을 먼저 획득, 핵이 시야를 벗어남, 이동 명령 덮어쓰기·재접속 | 내가 받은 핵과 사라진 대상을 구분하고, 분대가 최신 명령을 향하는지 알아본다. |
| 건설 비용 부족, 착공·완공, 4번 수비대로 양성, 야전 증원 도중 손실 | 왜 배치할 수 없는지, 새 원소가 어느 분대에 소속됐는지, 몇 기가 도착했는지 확인한다. |
| 수비대 2기에서 빠른 전송, 마우스로 지정 수량 보내기, 시야 밖에서 본진 피격, 양자 이동 중단 | 두 전송의 출발·목적·수량을 구분하고, 경보가 가리키는 위치와 귀환의 실제 결과를 알아본다. |
| 1280×720·UI 110%의 밀집 전장, 무음·동작 줄이기 | 선택·이동·획득·피격을 모양과 문구로 구분하고, 안내가 전장 조작과 경보를 가리지 않는다. |

현재 근거는 기존 HUD의 Editor 캡처와 규칙·코드 확인이다. 개편안의 가독성, 초행자의 이해, 밀집 전장에서의 표시 비용은 시제품과 실제 플레이에서 확인한다.
