# AI별 난이도와 전장 위 현황판

## 변경

- LAN·인터넷 대기실의 각 AI 행에 쉬움·보통·어려움 선택을 추가했다. 방장만 변경하며 다른 참가자는 선택 결과를 본다. 복구 중에는 변경을 막는다.
- 추가한 AI는 보통이며 마지막 AI부터 제거한다. 남은 AI의 난이도는 유지한다. 시작 시 각 군단에 적용하고 디스크 저장·복원 및 대기실·전장 승계에도 보존한다. 난이도 필드가 없는 동일 데이터 버전의 저장은 보통으로 복원한다.
- `gamedata.json`의 `ai`를 임시 경로로 등록했다. 판단 주기는 쉬움 0.75초, 보통 0.25초, 어려움 0.1초다. 어려움은 관측한 적의 상성을 고려해 현재 양성 가능한 원소를 고르고, 적을 관측한 상태에서 군단 체력 합계가 최대 체력 합계의 40% 미만이면 본진으로 후퇴한다. 후퇴는 본진 도착까지 유지하며 승계에도 보존한다. 자원·전투 능력치·시야 보너스는 없다. M0 부하 봇은 기존처럼 매 틱 판단한다.
- 현황판을 불투명하게 초기화하던 경로를 수정했다. 전체 화면 그림을 제거하고 투명한 입력 차단막을 유지해 전장이 배경으로 보인다. Tab 누름·뗌, 현황 버튼, 상성표와 뒤로 동작은 유지한다.
- 프로토콜 v15의 `LobbyState`에 AI별 난이도를 넣고 `LobbyAiDifficulty`(33)를 추가했다. 방장 권한, AI 순번, enum 범위와 패킷 길이를 서버에서 검증한다. 서버·클라이언트·중계는 같은 버전과 데이터 해시를 사용해야 한다.

## 남은 확인과 적용

- Unity Play, Windows Player와 외부망에서 사람이 조작하는 검증은 하지 않았다. AI 난이도의 체감과 후퇴 기준은 플레이테스트로 조정한다.
- 기존 인터넷 중계 PID 27720이 `ElementalLegion.Shared.dll`을 사용 중이어서 인터넷 테스트용 캐시 빌드는 MSB3027/MSB3021로 실패했다. 해당 중계는 계속 실행 중이며 갱신되지 않았다. 기존 친구 테스트 창을 종료하고 `Start-Server.cmd`의 5번으로 다시 시작하면 최신 코드와 데이터를 빌드한다.
- 데이터 해시 검증은 유지한다. 이번 데이터 추가 전의 해시를 가진 저장 파일을 자동 변환하지 않는다.

## 재사용 조사

2026-11-05에 기존 조사 후보인 [OpenRA AI 설정](https://github.com/OpenRA/OpenRA/blob/bleed/mods/ra/rules/ai.yaml)과 [GPL-3.0 라이선스](https://github.com/OpenRA/OpenRA/blob/bleed/COPYING)를 다시 확인했다. 설정으로 판단·행동을 구분하는 흐름을 참고했으며 코드는 복사하지 않았다. 기존 `BotBrain`, 대기실 코덱, uGUI 드롭다운과 저장·승계 경로를 확장해 새 패키지는 추가하지 않았다.
