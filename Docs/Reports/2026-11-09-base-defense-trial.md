# 본진 피해 한도 시험

2026-11-09 개발 브랜치의 자동 규칙 검증 결과다. 사람의 대응 시간이나 재미를 측정한 결과는 아니다.

기존 JSON의 시험값 250HP/초를 사용했다. 20Hz에서는 자기권이 먼저 흡수한 뒤 본진 체력에만 틱당 합산 12.5HP를 적용한다. 공격자가 다른 소유자여도 같은 본진의 한도를 공유한다. 자기권 직접 공격과 외곽 시설은 원래 피해를 받으며 초과 피해를 다음 틱에 적립하지 않는다.

| 자동 검증 | 확인 결과 |
| --- | --- |
| 1·4·20 공격자, 원소·소유자·처리 순서 변경 | 본진 합산 피해가 틱당12.5 이내 |
| 작은 타격 합산·자기권 초과 피해 | 실제 체력 피해만 예산·이벤트에 반영 |
| 서로 다른 본진·직접 자기권·외곽 시설 | 본진별 독립 한도, 외곽과 자기권 원래 피해 |
| 본진2000HP에 매 틱 한도만큼 적용 | 159틱 생존,160번째 피해 틱에 파괴 |
| 10Hz/90HP·40Hz/300HP 설정 | 각각 틱당9HP·7.5HP |
| 정리·유령·저장·승계 | 패배 보상은 한 번, 다음 틱 예산 초기화 동등 |

160개의 연속 피해 틱은20Hz에서8초다. 이는 규칙으로 계산한 최단 시간이며 실제 교전·입력 지연·사람의 반응을 측정한 시간이 아니다. 본진별 예산 캐시는 저장하지 않는다. 상태 캡처는 틱 경계에서 하고, 복원 후 다음 Step은 틱을 증가시킨 뒤 새 예산으로 시작한다.

BaseDefenseBudgetTests 18개를 포함한 관련 집중48개는 통과했다. 전체 결과는 메인 구현 보고서와 `.artifacts/main-world-trial/task6/`에 기록한다. 독립 리뷰에서 확인한 결함은 없었고 Unity 공유 코드 컴파일도 통과했다.

정식 채택은 보류한다. 2~4인이 경보를 보고 처음 입력하는 시간, 약5초 안에 개입할 수 있는지, 공격자의 외곽 시설 파괴 성과를 실제 플레이로 비교해야 한다. 이번 변경은 개발 중 시험용이며 운영 저장 변환·배포를 수행하지 않았다.
