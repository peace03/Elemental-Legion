## 이어서 유지할 플레이 동작

- **분대와 카메라.** 야전 1~3번, 수비대 4번, 전체 야전 5번이다. 번호키 선택에 카메라가 따라가고, `B`는 선택을 유지하며 본진을 보여 준다. 빈 분대도 중심을 이동시켜 증원을 받을 수 있다. 전장·미니맵 우클릭과 드래그는 지점 이동이고 미니맵 좌클릭 드래그는 카메라 이동이다. 지점 이동은 건물을 우회한다. 직접 이동 중 원소는 중심을 따라가면서 사거리 안의 적을 공격하며, 이동 입력이 끝나면 자동 추적을 재개한다.
- **집결과 양성.** 수비대는 `G` 또는 야전 집결 명령을 받아 출발한다. 집결 중에도 새로 양성한 원소에 명령할 수 있고, 이동 중과 본진 대기 인원을 따로 표시한다. 수비대로 집결은 반대로 야전 병력이 본진에 걸어와 합류하는 명령이다. 양성 목록에는 근접·중거리·원거리를 표시하고 1~4기와 목적 분대를 지정한다. 예약은 순서대로 진행하며 개별 대기 주문을 취소할 수 있다. 실제 선택한 주력 원소에만 주력 비용 할인과 2초 양성 단축을 적용한다.
- **귀환·전향·구출.** `R` 양자 이동은 선택한 야전 분대가 본진으로 돌아오는 서버 판정이다. 다음 이동에서 일반 진형으로 정렬한다. 중립은 성공 시 즉시 전향하고, PvP는 막타 분대가 후보를 확보하거나 원래 소유자가 구출할 수 있다. 합류 중 증원의 막타 권리는 **합류 목적 분대**에 예약된다. 증원 자신은 정식 합류 전까지 확보 진행·경합·시너지에 참여하지 않는다. 무료 시작 병력은 전향 후보와 핵 보상을 만들지 않는다. [게임 규칙](Docs/Rules/gameplay.md)
- **초반 성장과 시험값.** 현재 일반 월드의 신규 입장은 1레벨·야전 8기·수비대 4기·0핵이다. 다시 시작할 때도 다른 본진과 살아 있는 원소에서 떨어진 자리로 배치한다. 중립은 본진 건설 범위 밖에 1~4기씩 나타나며, 에너지 원소를 포함해 플레이어를 추적하고 범위를 벗어나면 돌아간다. 타워는 중립도 공격한다. 12기 시작·본진 피해 한도 250HP/s·PvP 후보 20초는 승인된 개발 시험값이다. [메인 월드 전환 기록](Docs/Reports/2026-11-09-main-world-rollout.md)
- **전장 시야와 표식.** 주 화면에는 보이는 지형 전체를 표시하고, 탐색 기록과 미탐색 구분은 미니맵에 둔다. 유닛·시설 정보는 서버의 시야 필터를 거친다. 미니맵 카메라 조작과 별개로 서버 카메라 시야의 기준은 자기 분대나 본진이다. 작은 흰 중심점은 유지하고 큰 상시 분대 원은 제거했다. 1~4개 마름모는 실제로 그린 원소 무리의 화면상 위쪽 중앙에 붙는다. 소속·건설 범위 선은 얇게 표시한다. [클라이언트 구조](Docs/Rules/architecture.md) · [플레이 피드백](Docs/Reports/2026-11-10-play-feedback.md)
- **HUD와 화면.** 타이틀에서 닉네임을 입력하며 입력 상태를 표시하고 소리로 알린다. 설정에서 음량·화면·조작 키를 조정한다. 건물과 건설 목록의 설명, 원소 상성표와 그래프를 제공한다. 현황판 뒤에는 전장이 보이고 왼쪽에는 내 상세 현황, 오른쪽에는 접속자 순위와 합산 점수만 표시한다. 순위는 현재 완공 시설·본진 레벨·생존 원소를 기준으로 하고 누적 공성 결과는 본인 여정에 남긴다. `Tab`으로 연 현황판은 키를 떼면 닫힌다. 일반 HUD 선택·재편 수량·집결 조작 중에도 이동 입력을 받는다. `Enter`로 채팅을 열고, 작성 중 `Tab`으로 근접·전체를 바꾼다. 작성 중에는 이동을 차단하고, 메시지는 반투명하게 잠시 표시한다.
- **방과 재접속.** 같은 방에 친구와 AI를 섞을 수 있고 방장은 AI마다 난이도를 정한다. 정원, 최소 시작 인원 충족 여부와 맵 크기를 계산할 때는 사람과 AI를 함께 센다. 사람이 모두 준비하면 방장이 시작한다. 인터넷 참가자는 목록에서 방 제목을 보고 입장하며 방장은 비밀번호 없이 열거나 숫자 4~8자리로 잠글 수 있다. 같은 계정은 살아 있는 유령 기지와 병력을 되찾는다. [방 이용법](README.md#방-만들기와-접속)
- **인터넷 방의 수명.** 방장 PC의 서버가 전투와 시야를 판정하고 WSS 중계가 목록과 연결을 담당한다. 정상 퇴장에서는 다음 서버에 최종 상태를 넘기고, 장애에서는 검증된 최근 백업을 복원한다. 게임 화면과 참가자 연결을 유지하는 흐름이며 경제 명령은 자동 재전송하지 않는다. 사람이 모두 떠나거나 중계가 종료되면 방이 닫힌다. 강제 복구는 백업 이후 진행 일부가 되돌아갈 수 있다. [승계 규칙과 시험](Docs/Reports/2026-11-05-host-migration-validation.md)

## 별도 계획과 남은 피드백

- **HUD·분대 단축키 개편은 구현 전이다.** 숫자키를 떼면 선택하고 두 분대 키를 조합하면 최대 3기를 보내는 동작, 번호 미니맵, 양성·병력·건설의 공통 영역, 소개 카드·현황·설정이 대상이다. 현재 조작과 예정된 조합키를 구분한다. 계획의 대화 결정과 구현 기본안을 확인하고, 시안의 예시 수치 대신 실제 서버 관측값을 표시한다. [구현 계획](Docs/Plans/2026-11-11-ui-controls.md) · [화면 시안 9종](Docs/Art/Concepts/2026-11-11-ui-index.md)
- **시설 연출은 미커밋 변경으로 반영돼 있다.** 원시핵·포집기·응집로·점화로·수호 위성의 모델과 효과는 보고서에 있다. 포집 연출은 서버가 확정한 수집 사건과 시야를 통과한 시설 출처를 사용하므로 해당 기능을 확인할 때 서버도 같은 변경본으로 실행한다. [시설 계획](Docs/Plans/2026-11-11-facility-vfx.md) · [적용과 검증](Docs/Reports/2026-11-11-facility-vfx.md)
- **건설 후 타워 원소 지정과 건설 범위의 바닥 표시**는 별도 피드백에 남아 있다. 현재 게임 규칙에는 건설 때 선택한 타워 원소를 유지하는 동작이 적혀 있으므로 시설과 HUD를 개편할 때 해당 요청의 처리 상태를 확인한다. 시간제 근원 쟁탈전은 별도 모드 후보로 보류 중이다. [피드백 목록](명령어%20목록.txt) · [기획 요약](Docs/design-summary.md)

## 실행과 회귀를 확인할 때

- **실행.** `Start-Server.cmd` 메뉴는 1 일반, 2 M3 양성·전향, 3 M4 건설·공성, 4 M5 복귀·저장, 5 인터넷 친구 테스트다. 새 실행 모드를 넣을 때 메뉴와 README를 함께 갱신한다. Unity Hub에서 `client/`를 열고 `Assets/_Project/Scenes/Bootstrap.unity`로 시작한다. 인터넷 5번은 개인 도메인이나 공유기 설정 없이 중계와 임시 터널을 준비한다. 다시 열면 주소가 바뀌므로 배포한 테스트 빌드의 주소 파일을 갱신한다. 장기 운영은 HTTPS/WSS 중계 주소를 별도로 설정한다. [런처](Start-Server.cmd) · [친구 테스트](README.md#다른-집-친구와-테스트) · [운영](README.md#온라인-서버-운영)
- **호환과 권한.** 현재 서버·클라이언트는 프로토콜 **v22**와 같은 게임 데이터 해시를 사용한다. 이전 기록과 README의 일부 실행 안내에는 v21 표기가 남아 있다. .NET 10 서버가 위치·자원·전투·시야를 판정하며 클라이언트는 명령만 보낸다. 공유 코드는 UnityEngine 의존성이 없는 C# 9 / netstandard2.1이고 Unity 6000.6.0f1의 `client/`가 `file:../../shared`로 참조한다. 게임 수치는 JSON에서, 표현 조절값은 Inspector에서 관리한다. [프로토콜](Docs/protocol.md) · [작업별 검증](Docs/Rules/workflow.md#작업별-검증)
- **UI 수명과 시각 회귀.** 런타임 UI는 `RuntimeUiControls`를 사용한다. 기본 UI 생성 도구가 등록한 Undo가 Editor 크래시를 낸 이력이 있다. 파괴된 선택 UI를 읽어 원소 렌더링이 끊긴 오류는 일반 UI 선택을 이동 허용 조건에서 빼면서 제거했다. 원소 위에 다른 원소가 겹쳐 보이던 현상은 보호막·빙결에 전체 원소 메시를 사용하던 별도 표현 문제였다. 현재는 전용 외피를 그린다.
