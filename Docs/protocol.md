# 네트워크 프로토콜

현재 패킷과 연결 처리는 미구현이다. 이 문서는 확정된 통신 제약만 기록하며 실제 패킷 필드나 직렬화 형식을 정의하지 않는다.

M0의 `SimCommand`(`MoveDir`, `Train`, `Rally`)와 `WorldView`는 프로세스 내부 시뮬레이션 계약이다. 이 타입을 그대로 네트워크에 직렬화하지 않으며 메시지 ID·필드·버전은 M1에서 정의한다. 서버 집계인 `WorldMetrics`는 시야 밖 정보를 포함하므로 클라이언트에 전송하지 않는다.

- 전송 라이브러리: 서버와 클라이언트 모두 LiteNetLib 1.3.5.
- 포트와 전송 주기는 `shared/Data/gamedata.json`에서 읽는다.
- 접속 시 LF로 줄바꿈을 정규화한 gamedata.json의 UTF-8 바이트에 대한 SHA-256을 비교하고, 다르면 접속을 거절한다. 해시 계산은 `GameDataDocument`에 구현되어 있으나 접속 시 비교는 아직 없다.
- 클라이언트는 `MoveDir`, `Rally`, `Recall`, `Dash`, `Build`, `Train`, `UpgradeBase`, `Chat` 명령만 보낸다. 서버가 검증한다.
- 시야 밖 상태는 전송하지 않는다.
- 사망·전향·핵 드롭·시너지·채팅은 신뢰·순서 보장 채널, 위치 스냅샷은 비신뢰 채널로 보낸다.

패킷을 구현할 때 메시지 ID, 방향, 필드와 단위, 직렬화 순서, 채널, 검증 및 실패 코드, 버전 호환 규칙을 여기에 함께 기록한다.
