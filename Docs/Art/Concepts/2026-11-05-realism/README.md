# 사실주의 원소 시안

2026-11-05. 이 폴더의 시안은 AI로 제작한 표현 방향이며 Unity 스크린샷이나 구현 결과가 아니다. 원소 자체는 자연색으로 표현했고 UI의 소유자 구분 색상과는 별개다.

## 확정한 방향

사용자는 최초 시안의 사실감에 동의한 뒤 이동 가능한 형태를 요청했다. 이어 v2를 이동 상태로 채택하고 대기 상태를 추가로 요청했으며, 최종 답변으로 **“대기·이동 시안 모두 이 방향으로”** 확정했다. 실제 구현은 이 확인 이후 진행했다.

- 이동: `natural-mobile-v2.png`, `energy-mobile-v2.png`
- 대기: `natural-idle-v3.png`, `energy-idle-v3.png`
- 실제 구현·검증은 [작업 계획](../../../Plans/2026-11-05-element-realism.md)과 별도 실캡처를 기준으로 판단한다. AI 시안 자체로 컴파일·성능·실게임 품질을 검증한 것으로 간주하지 않는다.

- 자연 원소: 물·불·바람·연기·얼음·흙·번개. 실제 유체와 입자, 굴절·산란, 거친 표면을 조합한다.
- 에너지 원소: 빛·결정·붕괴·암흑물질·중력·자기장·생명. 광산란·광물 재질·입자·화면 왜곡·식물 형태를 조합한다.
- 자연 보드에는 축소 예시가 있으나 실제 게임 렌더링이 아니며, 에너지 보드에는 축소 예시가 없다. 시점과 재질은 방향 제안이며 실시간 성능·실제 줌에서의 식별성은 미검증이다.

## 기존 조사 후보 인계

아래는 앞선 조사에서 전달받은 후보이며, 이 시안 작업에서 원본의 가격·라이선스·호환성을 재검증하거나 파일을 도입하지 않았다. 도입 전 해당 버전의 조건과 의존성을 다시 확인한다.

- [Unity Particle Pack](https://assetstore.unity.com/packages/slug/127325): 프로젝트에 설치된 무료 후보로 전달받음. 기존 효과 재사용 우선 검토.
- [A.U.R.W URP Free](https://assetstore.unity.com/packages/vfx/shaders/a-u-r-w-urp-free-195139): 무료 후보, Unity 6000.0 URP 표기로 전달받음. 6000.6 호환성은 직접 검증되지 않음.
- [GPU Fog Particles](https://github.com/MirzaBeig/GPU-Fog-Particles): Unlicense, Unity 2020.3 Built-in 기준으로 전달받음. URP 적용 시 수정 필요.
- [Unity VFX Toolbox](https://github.com/Unity-Technologies/VFXToolbox): Unity Companion License 기반 베이크 작업 흐름 참고 후보로 전달받음. 실제 관련 저장소와 라이선스는 도입 전 재확인 필요.
- [Boat Attack Water](https://github.com/Unity-Technologies/boat-attack-water): 오래된 로우폴리 목표의 물 구현 아이디어 참고 후보로 전달받음. 라이선스 파일은 확인되지 않았으므로 원본을 도입하지 않는다.


## 이동형 v2 피드백 반영

사용자는 최초 시안의 사실감을 긍정했고, 이동 가능한 형태로 바꾸기를 요청했다. 기존 이미지를 각각 편집해 `natural-mobile-v2.png`, `energy-mobile-v2.png`를 별도로 만들었다. 14종을 그림자와 이동 흔적이 있는 부유 응집체로 표현했으며 두 보드에 축소 예시가 있다. 저장본에서 이름과 14개 대상을 확인했다. 이미지는 정지된 AI 시안이므로 실제 이동 애니메이션, 정확한 부유 높이, Unity 성능과 실게임 축척의 식별성은 검증하지 않았다. 사용자는 v2를 이동 상태로 채택했다.

## 대기형 v3 피드백 반영

사용자는 v2를 이동 상태로 삼고 가만히 있을 때의 시안도 요청했다. v2를 각각 편집해 `natural-idle-v3.png`, `energy-idle-v3.png`를 별도로 저장했다. 14종의 부유 개체와 대기 축소 예시를 확인했다. 에너지 계열은 여러 실루엣이 둥근 형태로 수렴한다. 이는 정지된 AI 시안이며 대기 애니메이션, 실제 부유 높이와 게임 내 성능·식별성은 검증하지 않았다. 사용자는 대기형도 같은 방향으로 확정했다.
