# 게임 규칙

세부 수치는 모두 gamedata.json에 있다.

- **전역 인구 예산:** 생존 원소와 대기 양성·중립 빈자리의 예약이 4,096칸을 공유한다. 새 입장과 양성은 필요한 전체 슬롯을 확보한 뒤 자원을 바꾸며, 완료·취소·사망·유령 정리는 각 예약을 한 번만 소비하거나 반환한다. 수비대 양성은 본진 레벨별 수비 상한도 예약한다.
- **무료 출처:** 신규 입장 때 지급한 원소는 PvP·중립 사망·유령 만료에서 전향이나 핵을 만들지 않는다. 무상 지급한 본진도 유령 만료 때 시설 정액 핵을 지급하지 않는다. 표지는 재접속·저장·승계에 유지하며, 기존 저장과 정규 획득 자산에는 소급하지 않는다.

- **원소:** 자연 7종(water, fire, wind, smoke, ice, earth, lightning)과 에너지 7종(light, crystal, decay, dark_matter, gravity, magnetism, life). 시작 원소는 자연 7종 중에서만 고른다.
- **상성:** 그룹마다 고리 순서(`rings`)가 있고, 각 원소는 고리에서 다음 1·2·3번째를 이기고 앞 1·2·3번째에게 진다. 같은 그룹 유리 ×1.25, 불리 ×0.8.
- **자연 대 에너지:** 1대1은 에너지가 이긴다. 에너지 원소가 `crossCounters`의 자연 원소를 공격할 때만 ×0.8이고, 그 밖의 그룹 간 배율은 ×1.0이다.
- **분대 이동:** 야전 1~3번과 수비대 4번은 각각 중심과 명령을 가진다. 번호키로 선택하면 카메라도 이동하고, 전체 야전 선택 5는 수비대를 제외한다. 방향키는 선택한 분대 중심을 고정 속도(`world.legionSpeed`)로 움직이고 우클릭은 지점 이동을 지정한다. 유닛은 중심점 주위 진형 슬롯에 서고, 이동 방향 기준으로 근접은 앞, 원거리는 뒤에 선다. 유닛별 이동속도 스탯은 없다.
  - 수비대의 중심과 원소는 본진의 `legion.garrison.radius` 안에 머문다. 지점 도착 후에도 뒤처진 수비대는 자기 자리까지 따라오며, 명시적으로 정지하면 현재 자리를 지킨다. B는 선택과 명령을 유지한 채 본진을 보여 준다.
  - 집결은 목적 야전 분대와 지정 수량을 명령한다. 합류 중인 원소와 본진 대기 수를 구분하며, 다른 원소가 이미 이동 중이어도 새 대기 병력에 집결을 명령할 수 있다. 합류 전에는 목적 분대의 시너지에 포함하지 않는다.
  - 중심점은 건물에 닿으면 멈춘다. 이동 중 막힌 유닛은 건물 한쪽을 따라 돌고, 목표로 가는 직선이 열리면 다시 목표를 향한다. 진형 슬롯이 건물 안에 있으면 군단 중심에서 해당 슬롯으로 가는 선의 첫 접촉점 바깥을 임시 자리로 삼는다.
  - 진형으로 복귀하는 원소가 중심에서 `legion.formation.catchUpDistance` 이상 떨어져 있고 자기 자리와도 슬롯 간격보다 멀면 `catchUpSpeedMultiplier`로 이동 속도를 높인다. 기본 속도로 한 틱 안에 자리에 닿을 수 있으면 가속을 끝낸다.
  - 같은 플레이어의 원소는 `legion.formation.minimumSeparation` 안으로 가까워지면 이동량과 건물 경계가 허용하는 만큼 벌어진다. 마주 오는 원소는 서로 비켜 간다.
- **이탈 공격:** 이동 입력이 없을 때 군단 원소는 슬롯에서 `legion.leashDistance`까지 벗어나 적 유닛이나 건물을 추적한다. 이동 키를 누르는 동안에는 중심점 주위 대형을 따라오며, 사거리 안의 표적은 기존 공격 주기에 따라 계속 공격한다. 이동 입력을 멈추면 자동 추적을 재개한다.
  - 2026-11-05에 [OpenRA의 AttackFollow](https://github.com/OpenRA/OpenRA/blob/bleed/OpenRA.Mods.Common/Traits/Attack/AttackFollow.cs)를 재사용 후보로 검토했다. 원본은 GPL-3.0-or-later이며 OpenRA의 Actor·Activity에 의존한다. 이번 이동 우선 조건은 기존 `MovementSystem`과 `CombatSystem`의 분리된 단계를 활용했다.
- **건설과 성장:** 본진 주변에 시설을 건설한다. 서버는 비용·해금·개수·건설 범위·점유를 확인한 뒤 비용을 차감하고 착공한다. 공사 중에도 시설 자리를 차지하고 공격받을 수 있다. 시야와 시설 기능은 `buildSeconds` 뒤 완공되는 틱부터 적용한다. 공사 중 파괴되면 비용은 소모된다. 타워는 자연·에너지 그룹 안에서 선택한 원소를 완공 후에도 유지한다. 업그레이드 비용, 인구와 타워 상한은 `baseLevels`를 따른다. 자기권은 본진 중심에서 본진 피해를 먼저 흡수한다.
- **공성:** 유닛 표적이 없으면 건물 표면까지의 거리를 기준으로 기본 공격을 한다. 타워는 타워 중심의 사거리 안에서 가장 가까운 적 또는 중립 원소를 공격한다. 양성소가 파괴되면 해당 시설의 진행 양성과 예약 인구가 해제된다.
  - 소유 시설에 실제 피해가 들어오면 소유자에게 본진 경보를 보낸다. 같은 본진 구역의 반복 경보는 `legion.defenseAlarm.repeatSeconds` 간격으로 묶고 저장·승계한다. 경보에는 공격자의 ID·좌표·방향을 넣지 않는다.
- **자동 공격:** 사거리 안에서 가장 가까운 적부터 친다. 플레이어 소속 `life`는 가장 가까운 부상 아군을 회복한다. 중립 생명은 기본 공격을 한다. 다른 플레이어는 모두 적이다(동맹은 게임 규칙이 아니다).
- **방 전장:** 인터넷·LAN 방은 준비 완료한 시작 인원에 비례해 면적을 정한다. 2인 기준 한 변은 240m이며, 재접속과 저장 복원 시 시작 인원을 유지한다.
- **중립:** 1~4기 무리를 구역마다 흩어 놓고, 시작 자연 무리는 각 군단의 시야 안에서 자동 교전 거리 밖에 배치한다. 에너지 무리는 중앙에 배치한다. 중립은 본진 건설 범위 밖에서 생성되며, 표적이 추적 범위를 벗어나거나 시야에서 사라지면 원래 자리로 돌아간다. 일반 서버와 방은 JSON에 별도 밀도를 사용한다. M0 부하 시나리오와 M3 데모는 전용 배치를 사용한다. [구역을 나눠 표본을 놓는 방식 참고](https://github.com/mmp/pbrt-v4/blob/master/src/pbrt/samplers.cpp)
- **초반 성장:** 맵 핵을 플레이어당 분당 20개 공급한다. 포집기 20핵, 자연 양성소 30핵, 타워 40핵으로 자원 수급·양성·수비 중 먼저 투자할 대상을 고른다. 이후 에너지 양성소 55핵, 자기권 75핵과 레벨 2/3/4 업그레이드 비용 45/70/95핵을 적용한다.
- **전향:** 직접 싸운 유닛이 처치한 적은 `economy.conversionChance` 확률로 처치한 플레이어의 아군이 되고, 아니면 핵을 떨어뜨린다. 중립은 `neutral.conversionChance`를 쓴다. 전향 권리는 막타를 친 유닛의 주인에게 있다. 전향 유닛은 원래 속성을 유지하고, 다시 전향되지 않는다(처치되면 항상 핵).
- **전향되지 않는 경우:** 타워가 죽인 적, 인구 상한을 넘는 전향은 핵으로 변한다.
- **전향 직후:** `economy.convertedHealthRatio`만큼 최대 체력 기준으로 회복한다(현재 1.0). 임시 상태·방벽·기존 표적을 제거하고 다음 틱부터 새 군단으로 행동한다. 같은 틱의 사망을 모두 인구에서 제거한 후 ID순으로 전향을 적용한다.
- **핵 드롭:** 할인 전 생성 비용 × `economy.coreDropRatio`를 `economy.coreDropRounding`의 `floor` 정책으로 내림한다(자연 5, 에너지 8). 군단 중심 또는 군단 유닛이 `economy.corePickupRadius` 안에 오면 자동 습득하며, 여러 후보는 최단 거리·플레이어 ID순으로 결정한다. `economy.droppedCoreLifetimeSeconds` 뒤 사라진다.
- **양성과 합류:** 주력 원소의 양성 시간은 `training.mainElementTimeDiscountSeconds`만큼 짧다. 예약이 확정되면 핵을 차감하고 인구 슬롯을 확보한다. 한 번에 1기씩 예약 순서로 양성한다. 대기 예약을 취소하면 핵과 인구 슬롯을 돌려받는다. 양성소가 파괴되면 해당 종류의 대기 비용을 돌려주고, 진행 중인 원소의 비용은 소모된다. 양성된 유닛은 본진 주변의 빈 자리에서 수비대로 대기한다. 집결 명령을 내리면 그때 있던 수비대만 군단으로 이동하고, 진형 슬롯 간격만큼 가까워졌을 때 합류한다. 집결 도중에도 다시 명령을 내려 새 수비대를 출발시킬 수 있다.
- **시너지 반응:** 상태를 붙인 원소와 터뜨리는 원소가 같은 군단에 함께 있을 때만 발동한다(`reactions`).
- **효과 중첩:** 같은 효과는 강도를 더하지 않고 만료 시간을 갱신한다. 다른 종류의 능력치 보정은 곱으로 적용한다. 반응 후에도 원래 상태는 유지한다. 방벽은 흡수량을 더하지 않고 갱신하며, 생명은 자신을 포함한 가까운 부상 아군을 최대 체력까지만 회복한다.
- **추가 타격·영역:** 연쇄·관통·광역은 대상을 중복 타격하지 않고 2차 피해에서 효과·반응을 재귀 발동하지 않는다. 증기·모래폭풍은 고정 위치 영역이다. 모래폭풍 선행 타격은 `triggerWindowSeconds` 동안 같은 군단의 기록만 인정한다. 화염 확산은 원래 화상의 피해량·남은 시간·피해 귀속을 보존한다.
- **수비대 출처:** 수비대의 일반 공격·상태 효과는 유효하지만 군단 시너지의 원인으로 인정하지 않는다. 상태는 부여 당시 군단 소속을 기록하며, 나중에 군단에 합류해도 과거 상태를 소급 인정하지 않는다. 이동 입력의 크기는 속도나 진형 간격을 바꾸지 않으며 0이 아닌 방향은 단위 방향으로 정규화한다.
- **로그아웃:** 군단과 본진은 그 자리에 남아 사거리 안의 적만 자동 공격한다. 진행 중인 양성과 건설은 취소하고 비용을 반환한다. `ghost.decaySeconds` 뒤 남은 자산을 핵으로 변환한다. 유령 본진이 먼저 파괴되면 남은 유닛에 일반 전향·드롭 규칙을 적용한다.
- **유령 복귀:** 살아 있는 유령을 소유한 계정만 같은 플레이어 ID와 기지·군단·핵·탐색 기록으로 복귀한다. 상시 월드에서는 유령이 사라진 뒤 새 시작 원소로 입장한다. 이미 시작한 방에서는 참가 자격과 유령이 모두 남아 있어야 복귀할 수 있다. 서버가 중지된 시간은 유령 타이머에 더하지 않는다.
- **본진 파괴:** 접속 중인 패배자의 남은 자산을 정리한다. 패배 화면의 **다시 시작**에서 서버와 시작 원소를 고른 뒤 1레벨·3기·0핵으로 시작한다.
- **새 입장:** 본진은 기존 본진과 `spawn.minBaseDistance` 이상 떨어진 자리를 사용한다. 본진과 시작 군단의 원소는 살아 있는 다른 플레이어 원소와 `spawn.minEnemyUnitDistance` 이상 간격을 둔다. 유령 기지와 유닛도 검사한다. 안전한 자리가 없으면 입장을 거절한다.
- **접속 순위:** 현재 완공 시설 수(본진 제외), 본진 레벨, 생존 유닛 수, 전투 승리 수에 `score`의 가중치를 곱해 더한다. 접속 중인 상대 본진을 파괴한 플레이어에게 승리 1회를 기록한다. 모든 접속자는 합산 점수만 보고, 세부 수치는 본인에게만 표시한다.
