# Unity 인스펙터와 수치 조절

| 값의 종류 | 원본과 조절 방법 |
| --- | --- |
| 공격력·속도·쿨타임·인구·시야·전송 주기 등 게임 규칙과 서버 설정 | `shared/Data/gamedata.json`을 단일 원본으로 유지한다. 클라이언트 인스펙터 값으로 덮어쓰지 않는다. |
| VFX 크기·색상·지속 시간, 사운드 음량, 카메라 연출, UI 여백 등 판정에 영향을 주지 않는 표현 설정 | 해당 컴포넌트의 직렬화 필드로 인스펙터에 노출한다. 여러 프리팹이 함께 쓰는 설정은 필요할 때 ScriptableObject로 공유한다. |
| 현재 체력·월드 틱·서버에서 받은 상태 등 실행 결과 | 조절용 필드와 구분한다. 디버그 표시가 필요하면 읽기 전용으로 보여 준다. |

- **디자이너가 조절해야 하는 표현 수치는 코드에 숨기지 않는다.** 기본은 `[SerializeField] private` 필드와 필요한 읽기 전용 프로퍼티다. 인스펙터 노출만을 위해 public 필드를 만들지 않는다.
- 조절 필드에는 한글 `[Tooltip]`으로 용도와 단위·영향을 설명한다. 관련 필드는 `[Header]`로 묶고, 유효 범위가 있는 값에는 `[Min]` 또는 `[Range]`를 적용한다.
- `OnValidate`는 Editor에서 값과 참조 오류를 알리는 보조 수단으로만 사용한다. 네트워크·파일 입력이나 런타임 값은 사용하는 경계에서 별도로 검증한다. `OnValidate`에서 월드 변경이나 자산 저장을 자동 실행하지 않는다.
- 필수 참조는 프리팹·씬에 연결하고 초기화 시 검증한다. 누락을 자동 검색으로 계속 감추지 말고 대상과 필드가 드러나는 오류를 남긴다.
- 게임 밸런스를 인스펙터에서 편집하는 도구를 만들 때도 JSON을 읽고 명시적인 저장 동작으로 같은 원본을 갱신한다. 별도 밸런스 복사본을 만들지 않으며, 서버 재로딩·데이터 해시·접속 호환성을 함께 처리한다. 실행 중 밸런스 변경은 별도 요구가 있을 때 설계한다.
- `shared/`에는 `[SerializeField]`, ScriptableObject, MonoBehaviour를 넣지 않는다. Unity 설정과 표현 코드는 `client/`에서 공유 데이터를 참조한다.
